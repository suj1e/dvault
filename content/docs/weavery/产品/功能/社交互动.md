# 社交互动

weavery 的社交体系:**通知中心**、**私信**、**关注 / 收藏**。

## 通知中心 `notifications`

> 聚合社区互动通知。

### 五类通知 + 筛选

顶部 Tab 按通知类型筛选:

| Tab       | 包含                                                    |
| --------- | ------------------------------------------------------- | ---------------------------------- |
| 全部      | 所有通知                                                |
| 赞与收藏  | 别人点赞、收藏你的作品                                  |
| 评论      | 收到的评论(含 [[产品/功能/帖子详情与Remix#@AI-助手      | @AI 助手]] 的评论,带"AI 评论"标签) |
| 关注      | 新粉丝                                                  |
| **Remix** | 你的作品被 [[产品/功能/帖子详情与Remix#Remix改编-再创作 | Remix 改编]]                       |

### 时间分组

通知按时间分组展示:

- 今天 / 昨天 / 更早

### 通知项元素

| 元素     | 说明                 |
| -------- | -------------------- |
| 头像     | 触发者               |
| 行为描述 | "XX 赞了你的《...》" |
| 时间     | 相对时间             |
| 未读标记 | 小红点               |
| 操作按钮 | "查看" / "回关"      |

AI 助手的评论通知带"AI 评论"标签以示区分。

### 通知文案模板

7 种通知的文案模板(带占位符与示例):

| 类型            | 文案模板                                                | 示例                                                               |
| --------------- | ------------------------------------------------------- | ------------------------------------------------------------------ |
| 赞              | `{用户} 赞了你的作品《{标题}》`                         | "陈默 赞了你的作品《从色块到情绪》"                                |
| 收藏            | `{用户} 收藏了你的作品《{标题}》`                       | "顾南 收藏了你的作品《从色块到情绪》"                              |
| 普通评论        | `{用户} 评论了你的作品《{标题}》`                       |                                                                    |
| 评论回复        | `{用户} 回复了你的评论:「{内容}」`                      | "苏航 回复了你的评论:「把『周一早上』翻译成配色本身就很有画面感」" |
| **AI 助手评论** | `AI 助手 [AI 评论] 评论了你的作品《{标题}》:「{摘要}」` | "AI 助手 …评论了你的文章「结尾可以更干脆一些」"(头像 + AI 标签)    |
| Remix           | `{用户} 基于你的作品改编创作了《{新标题}》`             | "云小织 基于你的作品改编创作了《深色模式的情绪色块》"              |
| 关注            | `{用户} 关注了你`                                       |                                                                    |

> [!info] AI 评论归属
> @AI 助手的评论归在「评论」tab,用 ai-tag 视觉区分,**无独立 tab**。

### 通知 CTA 按钮五态

| 场景             | 按钮                             | 链接               |
| ---------------- | -------------------------------- | ------------------ |
| 赞/收藏/普通评论 | "查看"                           | post.html          |
| AI 助手评论      | "查看"                           | post.html#comments |
| 评论回复         | "查看"                           | post.html#comments |
| Remix            | **"查看改编"**(唯一不同文案)     | post.html          |
| 关注(未互关)     | **"回关"**(button)               | —                  |
| 关注(已互关)     | **"已互关"**(is-done 灰底不可点) | —                  |

### Tab 与未读显示

- 五 Tab(data-filter):all/like/comment/follow/remix。**Tab 本身不显示数字角标**
- 顶部 page-sub 显示未读总数:**"{N} 条未读"**(如"3 条未读");全部已读后变 **"全部已读"**
- "全部标为已读"按钮(id=btn-read-all):无未读时 disabled(灰色不可点)
- 未读红点实现:每条 `.notif` 末尾 `<span class="unread-dot">`,已读 opacity:0(仍占位),未读整行背景 `color-mix(border 18%, surface)` 加粗

### 时间格式三态

- 今天:"X 分钟前" / "X 小时前"
- 昨天:**"昨天 HH:MM"**(如"昨天 21:40")
- 更早:**"M 月 D 日"**(如"8 月 6 日")

### 空状态

`.empty` 区块(初始 is-hidden):**"这个分类下暂时没有通知"**,带圆形加减图标。

### 操作

| 操作         | 行为                               |
| ------------ | ---------------------------------- |
| 全部标为已读 | 顶部按钮                           |
| 单条点击已读 | 点击通知即标记已读                 |
| 回关         | 关注通知可直接"回关"或显示"已互关" |

### 全局铃铛浮窗

**全站通用**(各页顶栏),提供通知速览(详见 [[全局规范#通知浮窗]]):

- 点击顶栏铃铛展开
- 显示最近 3 条通知摘要
- "全部已读"按钮
- "查看全部通知 →"链接跳通知中心

> [!note] 本页无浮窗
> notifications 页本身**无铃铛浮窗**(本页直接是列表;顶栏通知 icon 为 aria-current="page" 高亮态,无未读红点)。

## 私信 `messages`

> 一对一私信,IM 风格。

### 布局

| 区块 | 内容             |
| ---- | ---------------- |
| 左侧 | 会话列表(可搜索) |
| 右侧 | 聊天线程         |

移动端:左右切换显示。

### 会话列表项

字段顺序:头像(avatar-lg 46px 圆,渐变取首字)→ 会话信息(名字行 + 最后消息行)→ 时间 → 未读角标

| 元素                    | 说明                                                          |
| ----------------------- | ------------------------------------------------------------- |
| 名字行 `.conv-name`     | 700 + 可选 `.conv-ai` AI 标签(10px 黑底白字方块"AI",圆角 4px) |
| 最后消息 `.conv-last`   | 12px muted 单行 ellipsis                                      |
| 时间 `.conv-time`       | 12px muted tabular-nums:"10:24" / "昨天" / "周二" / "周一"    |
| 未读角标 `.conv-unread` | 18px 圆角胶囊黑底白字 11px 700;打开会话后从 DOM 移除          |

- 列表头副文案:**"和关注的人聊点具体的话题"**
- 搜索框 placeholder:**"搜索会话"**

### thread-head

- 左侧移动端返回按钮(图标 + "会话")
- 头像(avatar-lg)+ 名字 + 副标题 `.thread-sub`
- 副标题格式:**"{领域} · {在线状态}"**(如"AI 产品观察 · 2 分钟前在线");AI 会话:"AI 作者 · 昨天在线"
- 右侧:仅"主页"btn-ghost 按钮(链 profile.html?user=,移动端隐藏)

### 消息特性

| 特性     | 说明                   |
| -------- | ---------------------- |
| 消息气泡 | 我 / 对方区分          |
| 按天分隔 | 日期分隔线             |
| 正在输入 | 对方"正在输入"三点动画 |

### 气泡与输入区细节

- 气泡最大宽度:72%(>900px)或 82%(≤900px)
- 对方气泡:灰底描边,左上角直角;我的气泡:黑底白字,右上角直角
- 每条消息都带头像(我的固定 avatar-g1"我")+ 下方时间(.msg-time 11px muted)
- 按天分隔符 `.msg-day`(居中胶囊灰底,如"今天")
- 正在输入 `.msg-typing`:与对方气泡同色,三点依次延迟 0/.2s/.4s
- textarea placeholder:**"输入消息,Enter 发送"**,最小高 22px 最大 120px 自动撑高
- 工具按钮(右侧 34×34):插入图片 / **发送当前文章**(纸飞机 icon,**原型未实现实际发送,只有按钮占位**)
- 发送按钮:黑底白字"发送"高 34px
- 提示行:**"按 `Enter` 发送 · `Shift + Enter` 换行"**
- 发送行为:连续换行折叠为单换行;发送后约 1400ms 显示对方"正在输入"再追加预置回复

### 输入区

| 功能          | 说明                 |
| ------------- | -------------------- |
| 插图          | 发送图片             |
| 发送当前文章  | 把正在看的文章发过去 |
| Enter         | 发送                 |
| Shift + Enter | 换行                 |

### AI 作者会话

会话可包含 AI 作者(云小织):

- 带 AI 标签
- 其回复可"放进你的 AI 写作工作台"

#### AI 会话差异

- 名字后带 AI 胶囊标签;头像 avatar-g3"云";副标题前缀"AI 作者";数据 `ai: true`
- 回复话术提到工作台:**"已经按你的风格起了三个开头,放进你的 AI 写作工作台了,打开就能看到。"**(暗示 AI 产出可进工作台,但 UI 无"放进工作台"按钮,仅文案)

### 隐私控制

- 从作者主页"私信"按钮发起
- 隐私设置可限制"仅关注的人可发"(见 [[产品/功能/账户与治理#设置|设置 → 隐私]])

## 我的收藏 `favorites`

> 收藏夹,聚合文章 / 话题 / 作者。

### 筛选 Tab

| Tab  | 内容                      |
| ---- | ------------------------- |
| 全部 | 所有收藏                  |
| 文章 | 收藏的文章                |
| 话题 | 订阅的话题(显示"订阅于…") |
| 作者 | 关注的作者(显示代表作)    |

各 Tab 带计数。

### 四 Tab 计数

全部 18 / 文章 12 / 话题 4 / 作者 2(由 JS 从 DOM `data-kind` 统计,非硬编码);`.fav-count` pill(mono、1px border、tabular-nums)同步。取消收藏动画 `.is-removing`(opacity 0 + translateX(14px),200ms 后 remove)+ toast **"已取消收藏"**。

### 列表项

三类型完整字段:

| 类型 | 图标      | meta                                            | title                         | excerpt        | foot/extra                                                                               |
| ---- | --------- | ----------------------------------------------- | ----------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| 文章 | 书签      | tag(s) + **"文章"**(accent 600) + "作者 · {名}" | 标题                          | 摘要(2 行截断) | "收藏于 {时间}" + 阅读量(eye) + **"取消收藏"**                                           |
| 话题 | 列表/文档 | **"话题"** + "订阅于 {时间}"                    | 标题(链 topic.html?t=)        | 话题描述       | **"{N}人关注"**(如"1.2 万人关注") + 阅读量 + **"取消订阅"**                              |
| 作者 | 人群      | **"作者"** + "关注于 {时间}"                    | 作者名(链 profile.html?user=) | 作者简介       | **"{N}k 关注"**(如"12.8k 关注",无"人"字,无阅读量) + **代表作 extra 行** + **"取消关注"** |

> [!important] 取消按钮三态文案
> 文章="取消收藏" / 话题="取消订阅" / 作者="取消关注"。**单位差异**:话题用"人关注"(万/千中文),作者用"k 关注"(k 小写无"人")。数字单位混用见 [[待确认问题#Q2]]。

作者独有 `.fav-extra`:**"代表作 · {文章链接}"**(.author-link 600)。

### 空态

`.fav-empty`:书签图标 40×40(stroke-width 1.5,color border 极淡)+ h3 **"这里还空着"** + p **"把喜欢的文章、话题或作者收进来,稍后慢慢读。"** + 按钮 **"去逛逛"**(primary,链 feed.html)

### 操作

| 操作     | 适用 |
| -------- | ---- |
| 取消收藏 | 文章 |
| 取消订阅 | 话题 |
| 取消关注 | 作者 |

## 业务规则

1. **通知按类型筛选**:五类 Tab 互斥
2. **AI 通知带标签**:AI 助手的评论通知显示"AI 评论"标签
3. **私信可限权**:隐私设置控制谁能发私信
4. **收藏分类管理**:文章/话题/作者分开,操作语义不同(取消收藏/订阅/关注)
