# 创作者中心

创作者相关功能:**数据看板**、**我的**、**草稿箱**。

## 创作者数据 `dashboard`

> 给创作者的周度数据看板,量化创作表现与 AI 参与度。

### 页头

| 元素   | class          | 文案 / 样式                                                   |
| ------ | -------------- | ------------------------------------------------------------- |
| kicker | `.dash-kicker` | **"Creator Dashboard"**(mono uppercase,letter-spacing 0.08em) |
| 标题   | `.dash-title`  | "创作者数据"                                                  |
| 副文案 | `.dash-sub`    | **"阅读量、互动与 AI 创作用量的周度表现"**                    |

#### 时间范围切换(period-toggle)

三按钮一组(7 / 30 / 90 天),36px 高,选中态 `.is-active` 背景 `color-mix(border 30%, surface)` + 600。

> [!note] aria 用法
> 用 **`aria-pressed`**(非 `aria-selected`)标记当前选中的时间范围。

### 四项 KPI

精确数值与 delta:

| KPI             | icon                    | 数值            | delta     |
| --------------- | ----------------------- | --------------- | --------- |
| 总阅读          | 眼睛                    | 4,812           | `▲ 12.4%` |
| 互动            | 消息气泡                | 1,086           | `▲ 8.2%`  |
| **AI 创作用量** | 太阳 / 星芒(8 方向射线) | 326             | `▲ 31.0%` |
| 净增关注        | 双人                    | **+96**(带正号) | `▲ 6.7%`  |

#### delta 规则

- 全部固定文案 **"较上周"**,即使切换 30 / 90 天也不变(见 [[待确认问题#Q20]])
- `.up` 绿 + 600;`.down` 红 + 600(原型示例全 ▲,无 ▼ 实例,但 class 已定义)

#### KPI 数字样式 `.kpi-num`

`text-2xl`(32px)、`font-display`、800、`tabular-nums`、`letter-spacing -0.02em`。

### 时间范围

顶部切换:近 **7 / 30 / 90** 天。

### 四项 KPI(语义说明)

| 指标            | 说明                       |
| --------------- | -------------------------- |
| 总阅读          | 累计阅读量(带环比涨跌)     |
| 互动            | 点赞 + 评论 + 收藏(带环比) |
| **AI 创作用量** | 使用 AI 创作的次数(带环比) |
| 净增关注        | 新增粉丝 - 取关(带环比)    |

### 阅读趋势柱状图

- **柱状图**,按天 / 周 / 月 聚合
- `.panel-note`:**"unit: reads"**(mono);切换时间范围后变 **"unit: reads · {N}d"**
- `.chart` 高 232px,padding-top 28px,`--max` 由 JS 设为当前数据最大值
- `.chart-bar` 宽 `calc(var(--v)/var(--max)*100%)`,min-height 3px,顶部圆角,黑色
- `.chart-col.is-peak`:峰值柱变浅(`color-mix(accent, white 18%)`);7 天数据中**周五 926** 标记为 peak
- `.chart-col.is-today`:最后一列 label 变 fg + 600;7d label 顺序:周一 / 周二 / 周三 / 周四 / 周五 / 周六 / 今天
- `.chart-val`:数值默认 opacity 0,**仅 hover 显示**(绝对定位 top:2px,mono 11px)

#### 时间范围切换的数据映射(JS 内置)

| 范围 | 聚合                                              | 数据                      | MAX   |
| ---- | ------------------------------------------------- | ------------------------- | ----- |
| 7d   | 7 个日(周一-今天)                                 | …                         | 926   |
| 30d  | **4 个周**(第 1 周 / 第 2 周 / 第 3 周 / 第 4 周) | 1840 / 2104 / 1760 / 2410 | 2410  |
| 90d  | **3 个月**(第 1 月 / 第 2 月 / 第 3 月)           | 12840 / 15360 / 17620     | 17620 |

### AI 创作来源(特色)

环形图量化 AI 参与度,把创作拆成三类:

| 来源        | 说明               |
| ----------- | ------------------ |
| 纯 AI 初稿  | AI 起稿为主        |
| AI 辅助润色 | 人工起稿 + AI 润色 |
| 纯人工      | 无 AI 参与         |

中心标注整体 AI 参与率(如"68% AI 参与")。

#### 环形图参数

- SVG 104×104,圆 r=44,stroke-width 12,周长约 276
- 背景环:`#e5e7eb`
- 主弧(纯 AI 初稿):`#000000`,`stroke-dasharray="186.5 276"`,`stroke-dashoffset="25"`
- 次弧(AI 辅助润色):`color-mix(#000, white 55%)`,`dasharray="59.5 276"`,`offset="-161.5"`
- 中心 `<b>68%</b>` + `<span>AI 参与</span>`
- `.panel-note`:**"last 7d"**(切换时间范围**不更新**,见 [[待确认问题#Q20]])

#### 图例(swatch 10×10,radius 3px)

| 色                                  | 来源        | 占比 |
| ----------------------------------- | ----------- | ---- |
| ■ 黑 `#000`                         | 纯 AI 初稿  | 48%  |
| ■ 浅黑 `color-mix(#000, white 55%)` | AI 辅助润色 | 20%  |
| ■ 灰 `#e5e7eb`                      | 纯人工      | 32%  |

> [!important] AI 参与度可视化
> 中心 68% = 48% + 20% 即 AI 参与率。这是 weavery 的特色——**量化并展示 AI 在创作中的参与度**,呼应"AI 透明"文化。

#### grid 列(桌面)

## 我的 `me`

> 当前用户的个人中心,聚合自己的内容。

### 结构

```
┌─────────────────────────────────────┐
│  资料头 + 数据条                     │
│  头像 昵称                           │
│  已发布 N │ 关注 N │ 粉丝 N │ 获赞 N│
│  [编辑资料] [设置]                   │
├─────────────────────────────────────┤
│  [文章] [草稿] [收藏] [关注]         │
│  对应内容列表                        │
└─────────────────────────────────────┘
```

### 四个内容 Tab

| Tab  | 内容                          |
| ---- | ----------------------------- | -------- |
| 文章 | 已发布作品(带"已发布"状态标)  |
| 草稿 | 内嵌草稿管理(继续编辑 / 删除) |
| 收藏 | 跳 [[功能/社交互动#我的收藏   | 收藏夹]] |
| 关注 | 关注列表(可直接取关)          |

### 入口按钮

| 按钮     | 跳转                                                              |
| -------- | ----------------------------------------------------------------- | ------ |
| 编辑资料 | toast **"编辑资料(原型占位)"**(未跳实际编辑页,说明编辑资料页未做) |
| 设置     | [[功能/账户与治理#设置                                            | 设置]] |

### Tab 持久化

`localStorage["zd-me-tab"]` 记住上次 tab,刷新恢复(profile 页无此机制)。

### 文章卡片

`.post-foot` 三 stat(图标 + 数字):

| stat   | 图标                    |
| ------ | ----------------------- |
| 阅读量 | 眼睛                    |
| 点赞数 | 心形                    |
| 讨论数 | 评论气泡,文案"X 条讨论" |

部分文章只显前两项无讨论。

### 状态色

| class           | 色          |
| --------------- | ----------- |
| `.status-pub`   | 绿(success) |
| `.status-fav`   | 橙(warn)    |
| `.status-draft` | 同 warn     |

### me 的草稿行

- `.draft-ic`:编辑图标,40×40 圆角灰块
- 标题:省略号
- meta:"草稿" + "更新于 {时间}" + "约 {N} 字"
- 继续编辑:跳 `create.html` **无参数**(见 [[待确认问题#Q13]])
- 删除:**直接 remove,无二次确认**
- **没有 AI chip**

### me 的收藏卡片

- 显示"作者 · {名}"而非单纯作者名
- foot 仅含"收藏于 {时间}"+ 阅读量,**无点赞 / 评论 stat**

### 关注行 `.follow-row`

- `avatar-md`(44×44 圆)
- `.follow-bio` 格式固定 **"{一句简介} · {N}k 关注"**
- `follow-btn`(关注 ↔ 已关注)

### 空态 `.empty-note`

仅 padding 48px + muted 文案,**无图标无插画**(比 drafts / favorites 简陋)。

### stat-cell 点击行为

| stat        | 点击行为   |
| ----------- | ---------- |
| 已发布文章  | 切文章 tab |
| 关注        | 切关注 tab |
| 粉丝 / 获赞 | toast 占位 |

### 收藏 Tab

收藏 Tab 跳转至 [[功能/社交互动#我的收藏]](四 Tab、三类型列表项、取消三态文案的完整规格)。

## 草稿箱 `drafts`

> 集中管理未发布的草稿。

### 页头

| 元素        | 文案                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| page-title  | "草稿箱"                                                                |
| `.page-sub` | **"写了一半的想法都在这里。工作台会自动保存,任何时候回来都能接着写。"** |
| actions(主) | "新建写作"(primary → `create.html`)                                     |
| actions(次) | "返回我的主页"(ghost → `me.html`)                                       |

### 概览统计

`.stats-bar` **仅 3 列**(非 4):**全部草稿 6 / AI 辅助创作 3 / 累计字数 1.8k**。

| 指标                | 说明                 |
| ------------------- | -------------------- |
| 全部草稿数          |                      |
| **AI 辅助创作**篇数 | 标记使用了 AI 的草稿 |
| 累计字数            |                      |

#### 统计联动

删除草稿后重算 `stat-all`(剩余行数)、`stat-ai`(含 ai-chip 的行数);**`stat-words` 未联动**(见 [[待确认问题#Q12]])。

### section-row

- h2:"最近编辑"
- `.filter` 按钮 **"全部草稿"**(漏斗图标,原型**无实际筛选功能**)

### 草稿列表项 `.draft-row`

字段:`.draft-ic`(42×42 灰底编辑图标)+ `.draft-body`(标题链接 + meta)+ `.draft-actions`。

| 字段            | 说明                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------- |
| 标题            | a 标签跳 `create.html?draft={id}`;`.is-untitled` 时 muted + 600,格式 **"无标题 · {摘要描述}"** |
| 状态            | "草稿"                                                                                         |
| 更新时间        | "更新于 {时间}"                                                                                |
| 字数            | "约 {N} 字" 或 "约 {N}k 字"                                                                    |
| **AI 参与标记** | `.ai-chip`,见下                                                                                |

#### meta 分隔符

`.dot`(3×3 圆点);顺序:"草稿" · "更新于 {时间}" · "约 {N} 字" · (可选)ai-chip。

#### `.ai-chip`

黑底白字,11px / 600,sparkle 图标。**原型中实际值仅两个:"AI 起稿"、"AI 续写"**(无第三种;无 chip = 纯人工)。

#### 草稿 id 示例

`draft-wb`、`draft-podcast`、`draft-prompt`(语义化命名,create 页据此回填)。

### 操作

| 操作     | 行为                   |
| -------- | ---------------------- | --------------------------- |
| 继续编辑 | 跳 [[功能/AI写作工作台 | 工作台]] `?draft={id}` 载入 |
| 删除     | **二次确认机制**(见下) |
| 新建写作 | 跳工作台新建           |

#### 删除二次确认机制

1. 第一次点:按钮变 **"确认删除?"** + `.is-confirm`(`borderColor` / `color` 设 danger)
2. **2.5s 内**再点:remove + toast"草稿已删除" + `updateStats()`
3. **2.5s 超时**:恢复原状

### 空状态 `.empty-note`

- `empty-ic`(56×56 圆角灰块 + 编辑图标)
- 标题:**"草稿箱是空的"**
- 引导:**"去工作台写下第一个想法,它会自动保存在这里"**

## 业务规则

1. **AI 参与全程可追溯**:草稿、看板都量化/标注 AI 参与度
2. **看板带环比**:KPI 显示同比涨跌
3. **删除二次确认**:草稿删除需确认(drafts 有 2.5s 二次确认机制,me 内嵌草稿直接 remove 无确认)
4. **me 页内嵌轻量管理**:me 的草稿/收藏/关注 Tab 对应独立完整页(drafts / favorites)
5. **看板切换不联动**:时间范围切换只重渲染柱状图,KPI / 环形图 / delta 文案不变(见 [[待确认问题#Q20]])
6. **drafts 路由带 id,me 草稿不带**:两处"继续编辑"路由不一致(见 [[待确认问题#Q13]])
7. **草稿字数不联动删除**:删稿后 `stat-words` 不重算(见 [[待确认问题#Q12]])

> 数据结构见 [[数据模型#草稿-draft]] / [[数据模型#ai-用量-aiusage]];dashboard / drafts / me 均为强登录页(见 [[权限矩阵#第一层页面访问权-auth-gate]]);看板切换不联动见 [[待确认问题#Q20]]、草稿路由不一致见 [[待确认问题#Q13]]。验收用例见 [[验收标准#创作者中心-验收]]。
