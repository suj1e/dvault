# 账户与治理

账户体系与社区治理:**登录注册**、**设置**、**社区准则**、**帮助中心**。

## 登录注册 `auth`

> 身份认证。

### 三态 Tab

| Tab | 用途 |
|------|------|
| 登录 | 已有账号 |
| 注册 | 新用户注册 |
| 忘记密码 | 找回 |

### 注册约束

- 注册需**同意《社区准则》**(checkbox 必勾)
- 邮箱校验
- 密码显隐切换

### 品牌区

登录页左侧品牌区呈现:

> "阅读、讨论,**用 AI 开始创作**。你的想法,值得被更多人看见。"

三条卖点:
1. AI 写作工作台:起稿、润色、续写,一键成文
2. 关注作者与话题,不错过任何一条好内容
3. 和志同道合的人讨论,让写作不再孤独

还有用户证言:
> "我在这里第一次用 AI 写完一篇想写很久的文章。" —— 云小织

### 提交流程

提交后 Toast 提示 + 跳转 feed。

## 设置 `settings`

> 账号资料、隐私、通知、个性化偏好。左侧分栏导航 + 右侧分区。

### 账号

| 字段 | 说明 |
|------|------|
| 公开资料 | 昵称、简介、地区 |
| 登录与绑定 | 邮箱、修改密码 |

### 隐私

| 选项 | 说明 |
|------|------|
| 私信开关 | 谁可以发私信(仅关注的人 / 所有人) |
| 被关注通知 | 新粉丝是否通知 |
| 隐藏关注列表 | 是否公开关注列表 |
| **允许用我的公开内容训练 AI** | 授权内容用于训练 |
| 导出我的数据 | 数据可携权 |

> [!important] AI 训练授权
> "允许用我的公开内容训练 AI"是 weavery 对 AI 伦理的体现——把是否贡献训练数据的选择权交给用户。

### 通知偏好

| 配置 | 选项 |
|------|------|
| 通知类型开关 | 评论 / 赞收藏 / 关注 / 话题动态 |
| 触达方式 | 邮件通知 |
| 汇总频率 | 实时 / 每天 / 每周 |

### 个性化

| 配置 | 选项 |
|------|------|
| 信息流是否展示 AI 内容 | 开关 |
| 默认排序 | 关注 / 热门 / 最新 |
| **AI 写作助手** | 默认模型(GPT-4o / Claude 3.7 / 本地模型)、自动保存草稿、语言偏好(简中/繁中/英) |

> [!note] 本地模型
> "本地模型 · 仅限已配置"选项,呼应 weavery 对本地优先 / 隐私友好的调性。

### 危险区

- **注销账号**:30 天冷静期(可恢复)

## 社区准则 `guidelines`

> 明文社区规则,既是治理依据也是产品调性宣示。

### 准则内容(8 条)

1. **尊重他人** —— 禁人身攻击、歧视
2. **认真创作,标注来源** —— ⭐ **AI 生成内容必须标注"基于 AI 生成"并附模型;分享提示词应附完整输入输出与参数**
3. **拒绝垃圾与广告**
4. **保护隐私**
5. **真实信息** —— 事实类需人工核实,不依赖 AI 捏造
6. **法律底线**
7. **执行与申诉**
8. **共同维护** —— 举报入口

版本 v1.0,最后更新 2026 年 8 月。

> [!important] AI 透明制度化
> 第 2 条把"AI 内容标注 + 提示词公开"从社区习惯上升为**强制规则**,是 weavery 文化的根基。

## 帮助中心 `help`

> 辅助页面,提供使用指引。原型中为占位,待完善。

## 业务规则

1. **注册必同意准则**:checkbox 必勾才能注册
2. **AI 训练需授权**:用户可选是否贡献训练数据
3. **注销有冷静期**:30 天内可恢复
4. **AI 内容强制标注**:社区准则第 2 条明文要求
