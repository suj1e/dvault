# 数据模型

## 核心数据结构

### Device

```yaml
Device:
  id: string (UUID)
  name: string (用户自定义)
  type: "macos" | "linux"
  status: "online" | "offline"
  capabilities:
    - filesystem
    - terminal
    - git
  currentSessionId: string | null
  createdAt: timestamp
  lastSeenAt: timestamp
```

### Workspace

```yaml
Workspace:
  id: string (UUID)
  name: string (用户自定义)
  path: string (本地绝对路径)
  deviceId: string (所属 Device)
  language: string | null (自动检测)
  createdAt: timestamp
  updatedAt: timestamp
```

### Session

```yaml
Session:
  id: string (UUID)
  workspaceId: string (所属 Workspace)
  deviceId: string (创建 Device)
  title: string (自动生成或用户自定义)
  status: "idle" | "running" | "paused" | "completed" | "failed" | "stopped"
  taskDescription: string (初始任务描述)
  model: string (使用模型)
  createdAt: timestamp
  completedAt: timestamp | null
  messages: Message[]
```

### Message

```yaml
Message:
  id: string (UUID)
  sessionId: string (所属 Session)
  role: "user" | "assistant" | "system"
  content: string (消息内容)
  timestamp: timestamp
```

### ToolExecution

```yaml
ToolExecution:
  id: string (UUID)
  sessionId: string (所属 Session)
  toolName: string (read_file / write_file / list_files / search_code / run_command)
  input: object (Tool 输入参数)
  output: string | null (Tool 执行结果)
  status: "pending" | "running" | "completed" | "failed"
  error: string | null (错误信息)
  startedAt: timestamp
  completedAt: timestamp | null
```

### Event

```yaml
Event:
  id: string (UUID)
  type: string (event type)
  sessionId: string | null (关联 Session)
  payload: object (事件数据)
  timestamp: timestamp
```

## 关系图

```
Device 1 ──N Workspace
Workspace 1 ──N Session
Session 1 ──1 Agent
Session 1 ──N Message
Session 1 ──N ToolExecution
Session N ──M Device (多端查看)
```

## 存储方案

### V1 本地存储

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| Device 信息 | macOS: `~/Library/Application Support/elysia/devices.json` | 设备元数据 |
| Workspace 信息 | macOS: `~/Library/Application Support/elysia/workspaces.json` | Workspace 列表 |
| Session 历史 | macOS: `~/Library/Application Support/elysia/sessions/` | Session 详细数据 |
| iOS: `Documents/elysia/` | 设备绑定信息，不跨设备同步 |  |
| Web: IndexedDB | 浏览器本地存储 |  |

### V1 云端存储（可选）

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| Session 索引 | 云端轻量索引 | 用于多端发现 Session |
| Event 历史 | 云端 | 用于 Web 端历史回看 |
| 文件内容 | 不存储 | V1 不存储代码内容 |

**V1 不存储**：
- 代码文件内容（文件在本地）
- Agent 的长期记忆
- 用户 Profile

## 数据流

```
User Input
  → Client
    → Session
      → Agent
        → Tool Execution
          → Workspace (本地文件系统)
        → Events
          → All Clients (实时更新)
```

## 状态机

### Session 状态机

```
                    ┌──────────┐
                    │   idle   │
                    └────┬─────┘
                         │ 用户创建 Session
                         ▼
                    ┌──────────┐
       ┌──────────▶│ running  │◀──────────┐
       │           └────┬─────┘           │
       │                │                 │
       │ 用户停止        │ Agent 完成       │ Agent 失败
       ▼                ▼                 ▼
  ┌─────────┐      ┌──────────┐      ┌──────────┐
  │ stopped │      │completed │      │  failed  │
  └────┬────┘      └────┬─────┘      └────┬─────┘
       │                │                 │
       └────────────────┼─────────────────┘
                        │ 用户 Resume
                        ▼
                   ┌──────────┐
                   │ running  │
                   └──────────┘
```

### Agent 状态机

```
              ┌──────────┐
              │  idle    │
              └────┬─────┘
                   │ Session 创建
                   ▼
              ┌──────────┐
       ┌──────▶│ thinking │◀───────────┐
       │       └────┬─────┘            │
       │            │                  │
       │ 思考完成     │ 调用 Tool       │ 用户停止
       ▼            ▼                  ▼
  ┌─────────┐  ┌──────────┐       ┌──────────┐
  │ stopped │  │  acting  │──────▶│ thinking │
  └─────────┘  └──────────┘       └──────────┘
                   │
              Tool 执行完成
                   ▼
              ┌──────────┐
              │ thinking │
              └──────────┘
```
