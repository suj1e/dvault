# 全局规范

> 所有功能页共用的契约——顶栏、登录态、设计 token、徽章、Toast、数字格式等。

## 全站顶栏

顶栏 `sticky` + 毛玻璃:`position: sticky; top: 0; z-index: 50`,背景 `bg 82%` + `backdrop-filter: blur(14px) saturate(1.4)`。

```
┌──────────────────────────────────────────────────────────────────────┐
│ [织] 云 Weavery   [🔍 搜索文章、话题或作者 ⌘K]   spacer   [+ AI 写作] [🔔●] [头像]│
│  brand            search(kbd)                          CTA     bell  user │
└──────────────────────────────────────────────────────────────────────┘
```

登录态结构(从左到右):

```
[织 方块 logo] [搜索框 placeholder "搜索文章、话题或作者" + ⌘K kbd] [spacer]
[mobile-search] [AI 写作 CTA(+icon,primary)] [铃铛 icon-btn 38×38 + bell-dot 未读红点] [头像 32×32 → user-pop 下拉]
```

| 元素        | 说明                                                                                                                                                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brand       | `.brand-mark`(28×28 黑底白字方块,字"织")+ `.brand-word`"云"(21px/800)+ `.brand-en`"Weavery"(12px/uppercase/`letter-spacing: 0.14em`,**768px 以下隐藏**);整链指向 `feed.html`                                        |
| 搜索框      | `form action="search.html" method="get"`,`input name="q"`,`max-width: 420px`,右侧 `<kbd class="search-kbd">⌘K</kbd>`(mono 11px,仿实体键帽 `border-bottom: 2px`);移动端(`<760px`)隐藏,显示 `.mobile-search` 图标按钮 |
| AI 写作 CTA | `.btn.btn-primary`,内含 `+` icon,`href="create.html"`                                                                                                                                                               |
| 铃铛        | `.icon-btn` 38×38,内嵌 `.bell-dot`(7px 黑点);点击展开通知浮窗(见下文"通知浮窗");aria-label 含未读数(见 [[待确认问题#Q1]])                                                                                           |
| 头像下拉    | `.user-pop`(240px)三段:`.user-head`(头像 36 + 用户名 + 角色如"认证作者")、`.user-list`(我的主页/草稿箱/我的收藏/偏好设置)、`.user-foot`("退出登录")                                                                 |

**未登录态**(`html[data-auth="out"]`):隐藏 AI 写作/铃铛/头像,显示 `.guest-only` 两个按钮——"登录"(描边,`href="auth.html"`)+ "注册"(黑底,`href="auth.html?mode=register"`);链接自动拼接 `?next=当前页`。

## 页脚(全站通用)

`.footer-brand`"织云 Weavery" + slogan **"阅读、讨论,用 AI 开始创作"** + 4 链接(搜索/通知/社区准则/帮助中心);移动端隐藏链接。

## 登录态机制

| 机制                | 说明                                                                                                                                                                                                                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 存储                | `localStorage["weavery-auth"]`,值 `in`/`out`                                                                                                                                                                                                                                           |
| 控制                | `html[data-auth]` 属性,内联脚本前置设置防闪烁(SSR 前置);`.authed-only` / `.guest-only` 两类元素据此显示                                                                                                                                                                                |
| 强登录页(auth gate) | 未登录访问以下页面会被 `location.replace` 到 `auth.html?next=...`:`me` / `drafts` / `favorites` / `settings` / `messages` / `notifications` / `dashboard` / `create`                                                                                                                   |
| 游客可访问          | `feed` / `post` / `profile` / `topic` / `search` / `guidelines` / `help`(只读浏览)                                                                                                                                                                                                     |
| 未登录拦截          | 点击交互元素(选择器 `.like-btn, .follow-btn, .action-btn, .fav-btn, #btn-like, #btn-fav, #pf-follow, #tp-follow, .remix-btn, [data-od-id^=like-], [data-od-id^=follow-]`)preventDefault + Toast **"登录后即可使用,请先 登录"**(Toast 内含 `auth.html` 链接,带 `next` 参数);显示 2600ms |
| 退出登录            | localStorage 设 `"out"` → 跳 `feed.html`(无二次确认)                                                                                                                                                                                                                                   |

> [!important] auth gate 基线
> auth gate 的强登录页清单是开发时要遵守的访问控制基线,游客可访问页仅作只读浏览。

## 全局快捷键

- **⌘K / Ctrl+K**:聚焦顶栏搜索框(preventDefault)
- **例外**:help 页优先聚焦帮助页内搜索框(逻辑:`helpInput.offsetParent !== null ? helpInput : mainInput`)
- search 页显示了 ⌘K 提示但未绑定快捷键(见 [[待确认问题#Q18]])

## 通知浮窗(全站顶栏铃铛)

`.notif-wrap`:铃铛点击展开 `.notif-pop`(344px,`max-height: 300px` 滚动)。

```
┌───────────────────────────────┐
│ 通知                 全部已读 │  ← .notif-head
├───────────────────────────────┤
│ ● [收藏] 云小织 收藏了你的…   │  ← .notif-item.is-unread
│ ● [评论] @AI 助手 评论了…     │  ← .notif-item.is-unread
│   [关注] 苏航 开始关注你      │  ← .notif-item
├───────────────────────────────┤
│ 查看全部通知 →                │  ← .notif-foot
└───────────────────────────────┘
```

- 结构:`.notif-head`("通知" + "全部已读"按钮)+ 3 条 `.notif-item`(收藏/评论/关注三种 icon)+ `.notif-foot`("查看全部通知 →")
- 未读项 `.is-unread`:浅灰底 + 左侧 6px 黑点
- "全部已读":移除所有 `is-unread` + 隐藏 `bell-dot` + aria-label 改为"通知"
- **ESC / 外部点击关闭**

通知项文案示例:

- **"云小织 收藏了你的作品《从色块到情绪》"**(2 分钟前)
- **"@AI 助手 评论了你的文章「结尾可以更干脆一些」"**(1 小时前)
- **"苏航 开始关注你"**(3 小时前)

## 徽章系统

这是 weavery 视觉语言的核心,每种徽章约定如下:

| 徽章            | class         | 样式                                                                                         | 文案                 | 用途                                                                                             |
| --------------- | ------------- | -------------------------------------------------------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------ |
| **AI 生成徽章** | `badge-ai`    | 1px 黑边/白底/胶囊/mono 字体,内含双星 svg                                                    | **"基于 AI 生成"**   | AI 内容强制标注(社区准则第 2 条)。**注意**:相关作品区有简写变体"AI"(见 [[功能/帖子详情与Remix]]) |
| **模型标签**    | `model-tag`   | 灰底胶囊(border 30% 混色)/ mono                                                              | 如"GPT-4o"           | 标注生成所用模型;也用于提示词版本(如"提示词 · v3")                                               |
| **讨论中**      | `badge-live`  | 绿色变体,内含 `.pulse-dot`(6px 圆点,`@keyframes pulse` 1.8s 无限脉冲,box-shadow 扩散)        | **"讨论中"**         | 高活跃讨论帖                                                                                     |
| **作者角色**    | `author-role` | 小方标。普通作者 **"专栏"**(黑字浅底);AI 作者变体 `.author-role.ai` = 黑底白字 **"AI 作者"** |                      | profile 页此样式未生效(见 [[待确认问题#Q19]])                                                    |
| **标签**        | `tag`         | 1px border 方形圆角,hover 变黑边                                                             | 如"技术"/"AI"/"设计" |                                                                                                  |
| **阅读时长**    | `readtime`    | text-xs muted                                                                                | 如"约 6 分钟"        |                                                                                                  |

## Toast 规范

- 实现:`.toast` `position: fixed; bottom: 28px; left: 50%`,`transform: translate(-50%,20px)` → `.is-show` 时 `translate(-50%,0)`;背景 `--fg` 黑、字白
- 显示时长:默认 2000ms;**未登录拦截类** 2600ms(因含链接需留阅读时间)

## 空状态规范

组合约定:图标(灰色,40–56px)+ 主文案(加粗)+ 副文案(muted)+ CTA 按钮(primary,跳相关页)。

示例:草稿箱空态 `.empty-ic`(56×56 圆角灰块 + 编辑图标)+ "草稿箱是空的" + "去工作台写下第一个想法,它会自动保存在这里"。

## 数字格式化

- 主函数 `fmt(n)`:**≥10000 → "X.X 万"**(去 `.0`,如 `12000 → "1.2 万"`),否则原数
- 现状不一致:卡片浏览数/点赞数用"万",但讨论统计、侧栏话题热度、推荐作者粉丝数用"k"(如 `9.6k` / `12.4k`)——见 [[待确认问题#Q2]]

> [!tip] 待统一项
> "万"与"k"混用是待统一项,见 [[待确认问题#Q2]]。

## 数据契约(localStorage 键全集)

| key                                   | 用途                              |
| ------------------------------------- | --------------------------------- |
| `weavery-auth`                        | 登录态 in/out                     |
| `zd-draft-title` / `zd-draft-content` | 工作台草稿标题/正文               |
| `zd-console-log`                      | 对话日志(只留最近 30 条)          |
| `zd-wb-step`                          | 斜杠命令素材池游标 `{p1, ct, ti}` |
| `zd-wb-split`                         | 工作台 splitter 宽度              |
| `zd-wb-pane`                          | 工作台移动端当前 pane(对话/文档)  |
| `zd-feed-tab`                         | 信息流当前 Tab                    |
| `zd-me-tab`                           | me 页当前 Tab                     |
| `zd-published-count`                  | 已发布篇数(原型写入但未读取)      |

> [!tip] 复用 key
> 开发时可直接复用这些 key 作为前端持久化契约。

## 无障碍

- `prefers-reduced-motion`:禁用 pulse 动画、card hover transform、cover/thumb svg scale、打字机等动效
- aria 约定:icon-btn 带 aria-label;Tab 用 `role=tablist`;表单 input 带 aria-label
- 聚焦环统一(`0 0 0 2px bg, 0 0 0 4px accent`)
