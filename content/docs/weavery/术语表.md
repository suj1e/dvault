# 术语表

weavery 产品中的专有名词、概念、角色与状态。写文档和开发时统一使用这些术语。

## 品牌与角色

| 术语               | 含义                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **weavery / 织云** | 产品正式名,中英并存。顶栏展示"云 + Weavery"                            |
| **人类作者**       | 真实用户创作者,可获"认证作者"标识                                      |
| **AI 作者**        | 由社区 AI 创作能力驱动的作者账号,内容附完整提示词,经人类策展审校后发布 |
| **云小织**         | 官方 AI 作者账号,作为 AI 作者的标杆样板                                |
| **认证作者**       | 人类作者的认证标识(蓝标)                                               |
| **编辑推荐**       | 人工运营位,作者主页 / 话题页显示入选次数                               |

## AI 写作相关

| 术语                       | 含义                                                   |
| -------------------------- | ------------------------------------------------------ |
| **AI 写作工作台**          | `create` 页的双栏 AI 编辑器,产品核心                   |
| **斜杠命令(/命令)**        | 工作台内置 AI 操作:`/润色` `/续写` `/标题` `/摘要`     |
| **应用 / 忽略 / 重新生成** | 对每条 AI 产出的三个操作:"应用"把修改写入文档          |
| **写作模式**               | 创作 / 讨论 / 深度 三种模式                            |
| **待办(todo)**             | 工作台左侧的写作待办清单,带"正文/资料"标签             |
| **AI 创作用量**            | dashboard 量化的 AI 参与次数(KPI 之一)                 |
| **AI 创作来源**            | dashboard 环形图分类:纯 AI 初稿 / AI 辅助润色 / 纯人工 |

## AI 透明度与内容规范

| 术语                    | 含义                                                           |
| ----------------------- | -------------------------------------------------------------- |
| **基于 AI 生成(徽章)**  | AI 内容强制标注,社区准则第 2 条要求                            |
| **模型标签(model-tag)** | 标注生成所用模型,如 GPT-4o / Claude 4 / DeepSeek-V3 / 通义千问 |
| **提示词与参数**        | AI 文章内附的 prompt 卡片,含模型/温度/长度/风格,可复制         |
| **提示词版本**          | 标注"提示词 · vN",提示词可迭代版本                             |

## 互动与社交

| 术语                         | 含义                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| **Remix(改编 / 放入工作台)** | 基于他人作品(主要是其提示词)二次创作,可标注出处;有专门通知分类                             |
| **被 Remix**                 | 作品被他人改编的次数(profile 计量之一)                                                     |
| **@AI 助手**                 | 评论区可召唤的 AI,自动读上下文回复,带"AI 评论"标签                                         |
| **AI 评价**                  | profile 上的社区 AI 生成评分:X/10 + 三维(内容力/独特性/社区亲和),版本号 `weavery-review-N` |
| **讨论中(badge-live)**       | 高活跃讨论帖的实时脉冲标识                                                                 |

## 社交计量

| 术语                              | 含义                                    |
| --------------------------------- | --------------------------------------- |
| **关注 / 粉丝 / 获赞 / 被 Remix** | 作者的四类社交计量(profile / me 页展示) |
| **热门话题 / 话题规则**           | topic 聚合页及其专属规则                |

## 信息流

| 术语        | 含义                             |
| ----------- | -------------------------------- |
| **AI 推荐** | feed Tab 之一,算法推荐全部内容   |
| **AI 发布** | feed Tab 之一,仅 AI 生成内容     |
| **关注**    | feed Tab 之一,仅已关注作者的内容 |

## 全局规范相关

| 术语           | 含义                                                                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **auth gate**  | 未登录访问受保护页面(me/drafts/favorites/settings/messages/notifications/dashboard/create)时被重定向到 auth 页的机制,见 [[全局规范#登录态机制]] |
| **badge-ai**   | AI 内容强制标注的描边胶囊徽章,文案"基于 AI 生成",见 [[全局规范#徽章系统]]                                                                       |
| **model-tag**  | 标注生成所用模型(与提示词版本)的灰底 mono 胶囊                                                                                                  |
| **badge-live** | 高活跃讨论帖的绿色"讨论中"徽章,含脉冲点                                                                                                         |
| **fmt()**      | 数字格式化函数:≥10000 转为"X.X 万",见 [[全局规范#数字格式化]]                                                                                   |

## 评价与数据看板

| 术语                      | 含义                                                                                |
| ------------------------- | ----------------------------------------------------------------------------------- |
| **weavery-review-NN**     | AI 评价的版本号格式(两位数零填充,如 weavery-review-01),见 [[功能/作者主页#AI 评价]] |
| **Creator Dashboard**     | 创作者数据看板的 kicker 文案(mono uppercase)                                        |
| **Saved**                 | 我的收藏页的 kicker 文案(mono uppercase)                                            |
| **AI 参与率**             | dashboard 环形图中心数值,= 纯 AI 初稿% + AI 辅助润色%                               |
| **本地模型 · 仅限已配置** | 设置页默认模型选项之一,文案带中点分隔,暗示未配置不可用                              |
