# dvault

一个用 Markdown 写就的**知识保险库**。

这里收录我的笔记,笔记之间用 `[[双向链接]]` 互相关联,左侧可浏览文件树,右上角可全文搜索,右侧有知识图谱与反向链接。

## 如何新增笔记

1. 在 Obsidian(或任意 Markdown 编辑器)里写 `.md` 笔记,自由使用 `[[互链]]`、`#标签`、`> [!note]` 等语法
2. 把笔记放进本仓库的 `content/` 目录
3. 提交到 `main` 分支,GitHub Actions 会自动构建并部署到 `dvault.flooc.cn`

## 特色

- 🌐 **双向链接**:笔记间用 `[[ ]]` 互链,自动生成反向链接
- 🔍 **全文搜索**:右上角搜索框,快速定位
- 🗺️ **知识图谱**:可视化笔记之间的关联
- 📁 **文件树浏览**:左侧 explorer 按目录组织
- 🌗 **暗色模式** & **阅读模式**:右上角一键切换
- ✅ 支持 Obsidian 全套语法:任务列表、标注(callout)、LaTeX 公式等
