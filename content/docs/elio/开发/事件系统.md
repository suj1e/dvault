# 事件系统

## 为什么需要 Event

Elio 的学习状态是动态变化的：
- 用户完成练习 → 进度更新
- 词汇复习 → SRS 状态变更
- 错误记录 → 薄弱点更新

Event System 让这些状态变化可以被：
- UI 实时响应
- 数据持久化触发
- 分析统计更新

---

## 什么是 Event

Event 是应用内状态变化的通知。

```json
{
  "id": "evt_001",
  "type": "exercise.completed",
  "payload": {
    "languageId": "lang_001",
    "skillId": "skill_vocab",
    "isCorrect": true,
    "duration": 12
  },
  "timestamp": "2025-01-15T10:30:00Z"
}
```

## Event 生命周期

```
User Action
    ↓ 触发
Event
    ↓ 发布
Event Bus
    ↓ 分发
Subscribers
    ├── UI Update
    ├── Data Persistence
    └── Analytics
```

---

## 订阅者

| 订阅者 | 订阅范围 | 行为 |
|--------|---------|------|
| UI | 用户可见的 Event | 更新界面 |
| Persistence | 所有 Event | 保存到本地存储 |
| Analytics | 练习相关 Event | 统计数据 |

---

## V1 Event 不做什么

- 不做网络传输（V1 纯本地）
- 不做 Event 持久化（Event 即时处理，数据由 Persistence 保存）
- 不做复杂 Event Schema
- 不做 Event 回放

---

## 与数据层的关系

```text
Exercise
  → exercise.completed Event
    → Persistence: 保存 Exercise
    → Progress: 更新掌握度
    → UI: 显示结果
    → Analytics: 统计正确率
```

一个 Exercise 完成，触发多个数据层更新，通过 Event 解耦。
