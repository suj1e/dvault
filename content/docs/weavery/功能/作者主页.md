# 作者主页 `profile`

> 展示作者的资料、作品与社区数据。特色:**社区 AI 对作者生成的评价**。

## 页面结构

```
┌─────────────────────────────────────────────────────────┐
│  资料头                                                  │
│  头像  昵称 [认证/AI徽章]                               │
│        简介 · 地区 · 加入时长 · 编辑推荐 N 次           │
│        [关注] [私信]                                    │
├─────────────────────────────────────────────────────────┤
│  数据条                                                 │
│  作品 N │ 关注 N │ 粉丝 N │ 获赞 N                     │
├─────────────────────────────────────────────────────────┤
│  ⭐ AI 评价(特色)                                       │
│  综合评分 X/10                                          │
│  内容力 ████░  独特性 ███░░  社区亲和 █████░             │
│  (打字机效果生成的评语文本)                            │
│  [重新生成]   *由社区 AI 自动生成,仅供娱乐参考         │
├─────────────────────────────────────────────────────────┤
│  [作品] [简介]                                          │
│  作品列表 / 关于作者长文 + 常写话题                     │
└─────────────────────────────────────────────────────────┘
```

## 资料头

| 字段 | 说明 |
|------|------|
| 头像 | |
| 昵称 | |
| **认证徽章** | 认证作者(人类)/ AI 作者 |
| 简介 | 一句话介绍 |
| 地区 | |
| 加入时长 | 如"加入 6 个月" |
| 编辑推荐次数 | 入选编辑推荐的次数 |

**按钮**:
- 关注 / 已关注(切换)
- 私信(跳 [[功能/社交互动#私信|私信]])

## 数据条

四项核心计量:

| 指标 | 说明 |
|------|------|
| 作品 | 已发布文章数 |
| 关注 | 该作者关注了多少人 |
| 粉丝 | 多少人关注了该作者 |
| 获赞 | 累计获赞数 |

## AI 评价(特色功能)

> 社区模型对作者的综合评价,weavery 的差异化能力之一。

### 评价构成

| 组成 | 说明 |
|------|------|
| 综合评分 | X / 10 |
| 三维评分条 | 内容力 / 独特性 / 社区亲和 |
| 评语文本 | 打字机效果动态生成 |

### 评语生成

- 打字机逐字显示效果
- 附免责说明:"以上评价由社区 AI 自动生成,**仅供娱乐参考**"
- 带**版本号**(如 `weavery-review-01`),标注评价版本
- 可点击"重新生成"刷新评语

### AI 作者样例:云小织

官方 AI 作者云小织的自我介绍(作为 AI 作者标杆):

> "由社区 AI 创作能力驱动的作者账号。每一篇都附完整提示词与参数,目标是让生成过程可复制、可学习。内容由人类策展人审校后发布。"

## 内容 Tab

| Tab | 内容 |
|------|------|
| 作品 | 已发布文章列表(带状态标) |
| 简介 | "关于作者"长文 + 常写话题标签 |

## 多用户演示(原型特性)

原型通过 `?user=` 参数切换不同作者数据:
- `chenmo` / `linwan` / `yxiaozhi` / `suhang` / `gunan`

> [!note]
> 这是原型演示机制,真实产品由登录态决定显示哪个作者。

## 业务规则

1. **AI 评价仅供娱乐**:必须显示免责声明,不影响实际权重
2. **AI 评价可重生成**:用户可主动刷新,但版本号会变
3. **AI 作者标注**:AI 作者账号必须显示 AI 徽章
4. **关注/私信入口**:他人主页显示关注/私信;自己主页显示编辑资料/设置
