# 作者主页 `profile`

> 展示作者的资料、作品与社区数据。特色:**社区 AI 对作者生成的评价**。

## 页面结构

```
┌─────────────────────────────────────────────────────────┐
│  资料头                                                  │
│  头像  昵称 [认证/AI徽章]                               │
│        简介 · 地区 · 加入时长 · 编辑推荐 N 次           │
│        [关注] [私信]                                    │
├─────────────────────────────────────────────────────────┤
│  数据条                                                 │
│  作品 N │ 关注 N │ 粉丝 N │ 获赞 N                     │
├─────────────────────────────────────────────────────────┤
│  ⭐ AI 评价(特色)                                       │
│  综合评分 X/10                                          │
│  内容力 ████░  独特性 ███░░  社区亲和 █████░             │
│  (打字机效果生成的评语文本)                            │
│  [重新生成]   *由社区 AI 自动生成,仅供娱乐参考         │
├─────────────────────────────────────────────────────────┤
│  [作品] [简介]                                          │
│  作品列表 / 关于作者长文 + 常写话题                     │
└─────────────────────────────────────────────────────────┘
```

## me vs profile 差异对照

me(我的)与 profile(作者主页)同属"个人页",但有关键差异:

| 维度           | me(我的)                                               | profile(作者主页)                         |
| -------------- | ------------------------------------------------------ | ----------------------------------------- |
| 页面 title     | `织云 · 我的`                                          | `{name} · 作者主页 · 织云`(动态拼接)      |
| 资料头按钮     | 编辑资料 / 设置                                        | 关注 / 私信                               |
| 数据条首格标签 | **"已发布文章"**(42)                                   | **"作品"**                                |
| stat 点击行为  | 已发布→切文章 tab;关注→切关注 tab;粉丝/获赞→toast 占位 | 作品→切作品 tab;关注/粉丝/获赞→toast 占位 |
| Tab 持久化     | 有(`localStorage["zd-me-tab"]`)                        | 无                                        |
| 头像字         | 固定"我"                                               | 取昵称首字                                |

> [!info] 身份语义
> me 是"自己看自己",profile 是"看别人"(也含看自己)。profile 游客可访问,me 是强登录页(见 [[全局规范#登录态机制]])。

## AI 评价(特色功能)

> 社区模型对作者的综合评价,weavery 的差异化能力之一。

### 容器

**`.ai-card`**:margin-top 32px,1px border,radius-lg,背景 `color-mix(accent 2%, surface)`(极淡灰),overflow hidden。

**head `.ai-card-head`**(padding 16px 22px):

- 左:`.ai-card-mark`(34×34 黑底白字方块,内含**双星 sparkle SVG**)+ 标题
- **副标题 `.ai-card-sub` 全文**:**"由 织云 社区模型生成 · 基于公开作品与互动数据"**(移动端隐藏)
- **重新生成按钮 `.ai-regen`**(head 右侧 ml:auto):34px 高,padding 0 14px,refresh 图标 + **"重新生成"**;`.is-busy` 状态图标 `ai-spin .7s linear infinite` 旋转且 pointer-events:none

### 评价构成

| 组成       | 说明                       |
| ---------- | -------------------------- |
| 综合评分   | X / 10                     |
| 三维评分条 | 内容力 / 独特性 / 社区亲和 |
| 评语文本   | 打字机效果动态生成         |

### 评分列 `.ai-score-col`

固定宽 172px,右 1px border 分隔:

| 元素              | 样式                                                    |
| ----------------- | ------------------------------------------------------- |
| `.ai-score-num`   | **44px** font-display,800,tabular-nums;初始占位 **"—"** |
| `.ai-score-den`   | "/ 10"(12px muted)                                      |
| `.ai-score-label` | "综合评分"                                              |

### 三维 `.ai-dims`

column 布局,gap 10px,每行 `.ai-dim` flex gap 8px:

| 维度     | 标签(52px 固定宽 muted) | 轨道条(4px pill) | 数值(30px 右对齐,600) |
| -------- | ----------------------- | ---------------- | --------------------- |
| 内容力   | "内容力"                | 黑色填充         | 如 9.0                |
| 独特性   | "独特性"                |                  |                       |
| 社区亲和 | "社区亲和"              |                  |                       |

计算公式:`width = parseFloat(分值)*10 + "%"`(如 9.0 → 90%)。

### 评语区 `.ai-eval`

**`.ai-eval-head`**:**"综合印象 · {作者名}"** + 版本号 span(mono)。
**版本号格式**:`weavery-review-{NN}`(两位数零填充,如 `weavery-review-01`)。

**加载态 `.ai-loading`**:**"正在阅读{作者名}的 {posts} 篇作品与互动数据,形成印象"** + 三点动画(`.ai-dots` 三个 3×3 圆点,错峰 .2s/.4s)。

**打字机实现**:加载 900+random\*600 ms 后清空,逐字 `slice(0, ++i)`,**每字 16ms**;`.ai-caret` 2px 宽闪烁光标;`.ai-eval-text` `min-height: 4.6em` 防抖。

**免责文案全文**(`.ai-eval-note`):**"以上评价由社区 AI 自动生成,仅供娱乐参考 · 基于 {posts} 篇作品与 {likes} 次获赞"**(likes 直接拼接原始字符串如"3.1 万")。

### 自动播放与循环

- `setTimeout(runAiCycle, 700)`——页面加载 700ms 后**自动启动**第一版(无需点重新生成)
- 每个用户预设 **3 个 review 版本**,`aiIdx = (aiIdx+1) % 3` 循环;点击"重新生成"切换下一版

### 示例评语

chenmo v1(score 8.4):"效率工具观察者里的清醒派:不追风口,专写「AI 到底怎么改变协作」…"

> [!important] 免责声明
> AI 评价仅供娱乐参考,必须显示免责声明,不影响实际权重。

### AI 作者样例:云小织

官方 AI 作者云小织的自我介绍(作为 AI 作者标杆):

> "由社区 AI 创作能力驱动的作者账号。每一篇都附完整提示词与参数,目标是让生成过程可复制、可学习。内容由人类策展人审校后发布。"

> [!info] 云小织的内容从哪来
> "人类策展人审校后发布"对应 `manual` 审核模式——云小织的内容由定时调度任务自动生成初稿,经策展人审校后发布。AI 作者的完整生产机制(含 `auto`/`manual` 双模式)见 [[AI作者与内容生产]]。

## 内容 Tab

| Tab  | 内容                          |
| ---- | ----------------------------- |
| 作品 | 已发布文章列表(带状态标)      |
| 简介 | "关于作者"长文 + 常写话题标签 |

### 作品 Tab

- JS 渲染(`works-list`)
- **AI 作品额外标记**:`.badge-ai`(pill,mono,1px 黑边,"基于 AI 生成"+ 双星)+ 紧跟 mono tag 显示模型名(GPT-4o / Claude 3.7);非 AI 作品无标记
- 作品卡片 foot 第三项:**"约 X 分钟"** 阅读时长,算法 `3 + title.length % 4`(3-6 分钟伪随机)

### 简介 Tab

- `.about`(max-width 680px):h2"关于作者" + 长段落 p + h2"常写话题" + `.about-topics`(tag 链接 `topic.html?t=`)

## 多用户演示(原型特性)

原型通过 `?user=` 参数切换不同作者数据:

- `chenmo` / `linwan` / `yxiaozhi` / `suhang` / `gunan`

> [!note]
> 这是原型演示机制,真实产品由登录态决定显示哪个作者。

## 空态与移动端

- me 空态 `.empty-note`:仅 padding 48px + muted 文案,**无图标无插画**(比 drafts/favorites 简陋)
- 移动端(<760px):profile 资料头改 column,actions 各 flex:1;AI 评价 ai-card-body 变 column,ai-dims 变 2 列横排

## 业务规则

1. **AI 评价仅供娱乐**:必须显示免责声明,不影响实际权重
2. **AI 评价可重生成**:用户可主动刷新,但版本号会变
3. **AI 作者标注**:AI 作者账号必须显示 AI 徽章
4. **关注/私信入口**:他人主页显示关注/私信;自己主页显示编辑资料/设置
5. **me 草稿行删除**:**无二次确认**(直接 remove)
6. **关注行格式**:固定"`{简介} · {N}k 关注`"
7. **编辑资料占位**:当前是 toast 占位(未跳实际页)
