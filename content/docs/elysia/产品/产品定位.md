# 产品定位

## 是什么

Elysia 是一个 **Coding Agent Harness** —— 一个可以真正操作代码库、执行命令、验证结果，并可以从 Web、macOS、iOS 多端访问和控制的 Coding Agent 产品。

它不是聊天机器人，不是代码补全工具，而是一个**能真正帮你改代码、跑测试、验证结果的 Agent 执行平台**。

## 给谁用

- **独立开发者 / 小团队**：需要快速修复 bug、重构代码、写测试，但不想在 IDE 里反复手动操作。
- **AI 原生开发者**：习惯用自然语言描述任务，希望 Agent 直接在代码库上执行并反馈结果。
- **多设备用户**：在 Mac 上编码，在 iPhone 上查看进度，在 Web 上回看历史。

## 价值主张

> **让 Agent 真正动手改代码，你只需要看结果。**

区别于代码补全和聊天机器人：
- 代码补全：你写，AI 补
- 聊天机器人：你问，AI 答
- Elysia：你说，**Agent 做**，你看

## 与 DeepSeek Harness 的差异

| 维度 | DeepSeek Harness | Elysia |
|------|-----------------|--------|
| 定位 | 单端 Web UI | 多端原生 Harness |
| 客户端 | Web 为主 | macOS + iOS + Web 原生三端 |
| 执行环境 | 云端沙箱 | 本地优先，macOS 作为主要 Execution Node |
| 设备模型 | 无 | Device 是一等公民 |
| Session 多端 | 不支持 | 同一 Session 多端共同观察和控制 |

## 社区调性

- **工程师优先**：文档和界面服务于"真正写代码的人"
- **透明执行**：Agent 的每一步操作都可见、可追溯、可停止
- **本地优先**：代码在本地，Agent 也在本地跑，不轻易把代码上传到云端执行
- **克制功能**：V1 只做完整闭环，不做花架子

---

> [!important] 一句话总结
> Elysia 是 Agent 的"控制台 + 遥控器" —— Mac 上是控制台，iOS 上是遥控器，Web 上是观察屏。
