# 验收标准

## 定义

V1 完成的标志是：**用户可以通过 Elio 完成一次完整的学习闭环，从输入到进步。**

---

## 验收维度

### 1. 学习闭环

**标准**：用户可以完成一次完整的学习循环。

| 检查项 | 通过标准 |
|--------|---------|
| 内容输入 | 用户可以阅读文章、听音频、查词 |
| 词汇练习 | 用户可以复习词汇（SRS） |
| 阅读练习 | 用户可以完成阅读理解题 |
| 听力练习 | 用户可以完成听力理解题 |
| 写作练习 | 用户可以完成写作练习并获得反馈 |
| 进度更新 | 练习后进度自动更新 |
| 薄弱点识别 | 系统可以识别用户薄弱点 |
| 下一步推荐 | 基于掌握度推荐下一步内容 |

---

### 2. 词汇系统

**标准**：词汇学习是核心功能。

| 检查项 | 通过标准 |
|--------|---------|
| SRS 算法 | 基于遗忘曲线的间隔重复 |
| 自评机制 | 用户可以自评掌握程度 |
| 生词本 | 用户查词自动加入生词本 |
| 复习提醒 | 到期词汇提醒复习 |
| 掌握度计算 | 正确率反映词汇掌握度 |

---

### 3. 阅读系统

**标准**：阅读后必须配套练习。

| 检查项 | 通过标准 |
|--------|---------|
| 文章分级 | 内容按难度分级（Lv1-Lv5） |
| 阅读器 | 支持文章阅读 |
| 即时查词 | 点击单词查词 |
| 阅读理解 | 文章后配套练习题 |
| 错误记录 | 阅读错误自动记录 |

---

### 4. 听力系统

**标准**：听力材料带字幕，配套理解题。

| 检查项 | 通过标准 |
|--------|---------|
| 音频播放 | 支持音频播放 |
| 字幕同步 | 同步显示字幕 |
| 听力理解 | 配套理解题 |
| 错误记录 | 听力错误自动记录 |

---

### 5. 写作系统

**标准**：写作练习提供基础反馈。

| 检查项 | 通过标准 |
|--------|---------|
| 写作题目 | 提供写作题目 |
| 基础判分 | 拼写、关键词、基本语法 |
| 错误记录 | 写作错误自动记录 |
| 示例展示 | 提供参考答案 |

---

### 6. 进度系统

**标准**：学习进度清晰可见。

| 检查项 | 通过标准 |
|--------|---------|
| Streak | 连续学习天数准确计算 |
| 掌握度 | 各技能掌握度展示 |
| 学习时长 | 总学习时间统计 |
| 趋势图 | 学习趋势可视化 |
| 薄弱点 | 薄弱点自动识别 |

---

### 7. 内容管理

**标准**：用户可以管理学习内容。

| 检查项 | 通过标准 |
|--------|---------|
| 内置内容 | 提供分级内置内容 |
| 导入内容 | 用户可以导入外部内容 |
| 生词本 | 生词自动管理 |
| 内容浏览 | 按难度、类型浏览 |

---

## 用户故事验收

| Story | 验收标准 |
|-------|---------|
| Story 1：新用户首次使用 | 用户可以选择语言、设定目标、开始学习 |
| Story 2：词汇学习流程 | 用户可以完成 SRS 词汇复习 |
| Story 3：阅读学习流程 | 用户可以阅读文章并完成理解题 |
| Story 4：听力学习流程 | 用户可以听音频并完成理解题 |
| Story 5：写作练习流程 | 用户可以完成写作练习并获得反馈 |
| Story 6：每日学习流程 | 用户可以按推荐完成每日学习 |
| Story 7：生词本管理 | 用户可以管理生词本 |
| Story 8：进度查看 | 用户可以查看完整的学习进度 |

---

## 非功能性验收

| 维度 | 标准 |
|------|------|
| 性能 | 练习响应时间 < 1 秒 |
| 稳定性 | App 可以持续运行不崩溃 |
| 离线可用 | 核心功能离线可用 |
| 兼容性 | iOS 17+ |
| 可用性 | 用户无需阅读文档即可完成核心操作 |

---

## 完成定义（Definition of Done）

V1 完成的标志：

1. ✅ 用户可以选择语言并设定学习目标
2. ✅ 用户可以完成词汇 SRS 复习
3. ✅ 用户可以阅读文章并完成理解题
4. ✅ 用户可以听音频并完成理解题
5. ✅ 用户可以完成写作练习并获得基础反馈
6. ✅ 用户可以管理生词本
7. ✅ 系统自动记录错误并识别薄弱点
8. ✅ 用户可以看到完整的学习进度
9. ✅ 连续学习天数准确计算
10. ✅ 学习闭环完整：输入 → 练习 → 反馈 → 进步

满足以上全部 10 条，V1 完成。
