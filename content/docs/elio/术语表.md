# 术语表

## A

### App

Elio 应用。V1 为 iOS App。

### Article

文章。Elio 的核心学习内容之一，按难度分级。

---

## E

### Exercise

练习。用户完成的具体练习任务，包括词汇复习、阅读理解、听力理解、写作练习等。

---

## L

### Language

语言。用户正在学习的语言对象，包含技能进度、学习内容等。

---

## S

### Skill

技能。语言学习的维度，V1 包含：词汇、阅读、听力、写作、口语。

### SRS（Spaced Repetition System）

间隔重复系统。基于遗忘曲线的词汇复习算法，在最佳时间点复习词汇以加强记忆。

### Streak

连续学习天数。用户连续每天学习的日历天数。

---

## V

### Vocabulary

词汇。Elio 的核心学习单元，通过 SRS 系统管理复习。

---

| 缩写 | 全称 | 说明 |
|------|------|------|
| V1 | Version 1 | 第一个正式版本 |

| UI | User Interface | 用户界面 |

## 学习相关术语

| 术语 | 说明 |
|------|------|
| 掌握度 | 用户对某个技能或词汇的掌握程度，0-100% |
| 薄弱点 | 用户容易出错的知识点 |
| 遗忘曲线 | 描述记忆随时间衰减的曲线，SRS 的基础 |
| 间隔重复 | 在记忆即将消失时安排复习，提高长期记忆效率 |
| 主动回忆 | 通过主动提取信息来加强记忆，而不是被动重复 |
| 可理解输入 | 略高于当前水平的内容，是语言学习的核心理论 |
