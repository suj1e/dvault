# 话题与搜索

发现内容的两个入口:**话题页**(按主题聚合)和**搜索**(全局检索)。

## 话题页 `topic`

> 按主题聚合内容的专题页,类似社区版块。

### 页面结构

| 区块 | 内容 |
|------|------|
| 话题头 | `#话题名`、描述、讨论数 / 关注人数 / 编辑推荐次数 |
| 操作 | 关注话题 + 发帖(跳 [[功能/AI写作工作台|工作台]]) |
| 排序 | 最新 / 热门 / 讨论最多 |
| 侧栏 | 相关话题 + **话题规则** |

### 话题规则(特色)

每个话题有**专属规则**,约束该话题下的发布行为。示例规则:

- "AI 辅助产出请标注"
- "发布提示词请附示例输入与输出"

> [!important] 分版治理
> 话题规则实现了**分版块治理**——不同话题可以有不同的内容要求,比全局社区准则更细粒度。

### 内置话题

原型内置约 17 个话题,通过 `?t=` 参数渲染:

| 类别 | 话题 |
|------|------|
| 技术 | AI 编程、独立开发者、开源与商业化、大模型、模型对比、提示词 |
| 设计 | 设计系统、配色、渐变、生成式设计 |
| 效率 | 效率工具、工作流、AI 写作 |
| 生活 | 数字游民、职业成长、生活、翻译、写作 |
| 趣味 | 梗图 |

### 发帖入口

话题页"发帖"按钮跳工作台,并预填该话题标签。

## 搜索 `search`

> 全局搜索 + 无关键词时的探索发现页。

### 探索态(无关键词)

无搜索词时显示发现页:

| 区块 | 内容 |
|------|------|
| 大搜索框 | 输入关键词 |
| 热门搜索 chips | 如 配色 / 提示词 / 模型对比 / 翻译腔 / AI 编程 |
| 热门话题卡片 | 网格展示热门话题 |
| 推荐作者 | |

### 结果态

输入关键词后,结果按 Tab 分类:

| Tab | 内容 |
|-----|------|
| 全部 | 所有匹配 |
| 文章 | 匹配的文章 |
| 作者 | 匹配的作者 |
| 话题 | 匹配的话题 |

结果项包含:AI 标识、模型标签、阅读数等。

支持 URL `?q=` 直接进入结果态(便于分享/外链)。

### 空结果

无匹配时提示:"没有找到相关内容,换个关键词试试,或去工作台让 AI 写一篇。"

> [!tip] 引导创作
> 搜索无结果的引导文案直接指向工作台,体现了 weavery "找不到就自己写一篇"的创作社区定位。

## 业务规则

1. **话题有规则**:每个话题可设独立规则,约束发布
2. **话题排序三选一**:最新 / 热门 / 讨论最多
3. **搜索结果分类**:支持按 文章/作者/话题 过滤
4. **搜索可外链**:`?q=` 支持分享搜索结果
