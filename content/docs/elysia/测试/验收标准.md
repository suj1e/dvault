# 验收标准

## 定义

V1 完成的标志是：**用户可以用 Elysia 真正完成一个 Coding Task，从输入需求到验证结果，全流程无需离开产品。**

---

## 验收维度

### 1. Agent 闭环

**标准**：Agent 可以独立完成一个 Coding Task 的完整循环。

| 检查项 | 通过标准 |
|--------|---------|
| 理解任务 | Agent 正确解析用户输入的任务描述 |
| 查看代码库 | Agent 可以列出文件、读取文件内容 |
| 搜索代码 | Agent 可以搜索代码中的关键词 |
| 修改文件 | Agent 可以写入新内容到文件 |
| 执行命令 | Agent 可以运行终端命令并获取输出 |
| 验证结果 | Agent 可以运行测试验证修改是否正确 |
| 错误恢复 | Agent 遇到失败可以自动 Retry 或请求用户介入 |
| 完成任务 | Agent 可以确认任务完成并生成总结 |

---

### 2. macOS 客户端

**标准**：macOS App 是 V1 的主要 Execution Node。

| 检查项 | 通过标准 |
|--------|---------|
| 选择 Workspace | 用户可以选择本地文件夹作为 Workspace |
| 创建 Session | 用户可以创建新 Session 并输入任务 |
| 查看 Agent Activity | 实时显示 Agent 的思考过程和 Tool 调用 |
| 查看 Diff | 显示文件修改的 Diff |
| 查看 Terminal | 显示命令执行输出 |
| 停止 Agent | 用户可以随时停止 Agent |
| Session 历史 | 用户可以查看和 Resume 历史 Session |

---

### 3. iOS 客户端

**标准**：iOS App 是 Agent Controller。

| 检查项 | 通过标准 |
|--------|---------|
| 查看设备 | 显示用户拥有的 Device 列表和在线状态 |
| 查看 Session | 显示 Device 上的 Session 列表 |
| 查看 Activity | 实时查看 Agent 的 Activity |
| 发送消息 | 可以向 Agent 发送新消息 |
| 停止 Agent | 可以停止正在执行的 Agent |
| 实时更新 | Activity 实时更新，无需手动刷新 |

---

### 4. Web 客户端

**标准**：Web UI 可以独立完成 Session 观察和控制。

| 检查项 | 通过标准 |
|--------|---------|
| 创建 Session | 可以创建新 Session |
| 查看 Activity | 实时显示 Agent Activity |
| 查看 Diff | 显示文件修改 |
| 查看 Terminal | 显示命令输出 |
| 停止 Agent | 可以停止 Agent |
| 发送消息 | 可以向 Agent 发送消息 |

---

### 5. 多端同步

**标准**：同一个 Session 可以在 macOS / iOS / Web 上共同观察和控制。

| 检查项 | 通过标准 |
|--------|---------|
| Session 可见 | 三个端都能看到同一个 Session |
| 实时更新 | 一个端的操作，其他端实时可见 |
| 消息同步 | 在 iOS 发送的消息，macOS 上的 Agent 能收到 |
| 状态一致 | 三个端的 Session 状态保持一致 |

---

### 6. Event System

**标准**：Event System 可靠、实时、一致。

| 检查项 | 通过标准 |
|--------|---------|
| 实时推送 | Event 在产生后 1 秒内到达客户端 |
| 事件完整 | 所有状态变更都有对应 Event |
| 断线重连 | 断线重连后能恢复最新状态 |
| 事件顺序 | Event 按时间顺序到达 |

---

## 用户故事验收

| Story | 验收标准 |
|-------|---------|
| Story 1：创建 Workspace | 用户可以在 macOS 上选择文件夹创建 Workspace |
| Story 2：创建 Session | 用户可以输入任务描述创建 Session，Agent 自动启动 |
| Story 3：Agent 执行任务 | Agent 可以自主执行：搜索 → 读取 → 修改 → 运行测试 → 验证结果 |
| Story 4：错误恢复 | Agent 遇到失败可以自动 Retry 或请求用户介入 |
| Story 5：iOS 查看状态 | 用户可以在 iPhone 上实时查看 Mac 上的 Agent 进度 |
| Story 6：iOS 发送消息 | 用户可以在 iPhone 上向 Agent 发送新指令 |
| Story 7：Web 查看 Session | 用户可以通过 Web 查看同一个 Session 的实时状态 |
| Story 8：任务完成 | Agent 完成任务后，所有客户端收到通知并显示结果 |

---

## 非功能性验收

| 维度 | 标准 |
|------|------|
| 性能 | Agent 响应时间 < 5 秒（不含模型推理时间） |
| 稳定性 | Session 可以持续运行 30 分钟不崩溃 |
| 实时性 | Event 推送延迟 < 1 秒 |
| 兼容性 | macOS 14+, iOS 17+, 现代浏览器 |
| 可用性 | 用户无需阅读文档即可完成核心操作 |

---

## 完成定义（Definition of Done）

V1 完成的标志：

1. ✅ 用户可以在 macOS 上选择文件夹创建 Workspace
2. ✅ 用户可以创建 Session 并输入自然语言任务
3. ✅ Agent 可以自主执行 Task（搜索 → 读取 → 修改 → 运行测试 → 验证）
4. ✅ 用户可以在 macOS 上实时查看 Agent Activity、Diff、Terminal
5. ✅ 用户可以在 iOS 上查看同一 Session 的实时状态
6. ✅ 用户可以在 iOS 上发送消息给 Agent
7. ✅ 用户可以在 Web 上查看同一 Session
8. ✅ Agent 遇到失败可以自动 Retry 或请求用户介入
9. ✅ 用户可以在任意端停止 Agent
10. ✅ Event System 可靠运行，三端状态一致

满足以上全部 10 条，V1 完成。
