# AI 写作工作台 `create`

> weavery 的核心。双栏布局:**左侧 AI 对话 + 右侧文档**,AI 把修改直接写入文档。

工作台是整个产品的创作枢纽,被首页侧栏、话题页"发帖"、帖子页"编辑/放入工作台/Remix"、草稿箱等多处入口指向(见 [[信息架构]])。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  顶栏(全站通用)                                        │
├──────────────────────┬──────────────────────────────────┤
│  左栏:AI 对话面板    │  右栏:文档区                     │
│                      │                                  │
│  ┌─ 待办(可折叠)──┐ │  标题输入框                       │
│  │ ☐ 给第一段加钩子│ │  ──────────────                  │
│  │ ☐ 补充播客链接  │ │  正文 textarea(Markdown)         │
│  └──────────────────┘ │                                  │
│                      │  工具栏:加粗/斜体/引用/列表/    │
│  对话日志:           │          链接/插图               │
│  [我] 帮我润色第一段 │                                  │
│  [AI] (修改建议)     │  底部:字数 · 约 N 分钟读完       │
│   [忽略][重新生成]   │        [发布]                    │
│   [应用]             │                                  │
│                      │                                  │
│  输入框 + /命令      │                                  │
└──────────────────────┴──────────────────────────────────┘
```

- **桌面**:左右双栏,中间可拖拽 **splitter** 调整栏宽
- **移动**:切换为"对话 / 文档" Tab 单栏显示

## 页头说明

工作台**没有独立页头**,复用全站顶栏(见 [[全局规范#全站顶栏]])。

文档区顶部有 `.doc-toolbar`,含 **"返回首页"** 链接(带左箭头 `←`,链 `feed.html`);**移动端只剩箭头**,文案隐藏。工具栏其余按钮见下文 [文档区工具栏](#文档区工具栏)。

## 左栏:AI 对话面板

### 对话日志

聊天气泡式,共 **4 种消息类型**:

| 类型     | class         | 样式                                                                                   | 说明                  |
| -------- | ------------- | -------------------------------------------------------------------------------------- | --------------------- |
| 系统消息 | `log-sys`     | 居中横排、11px mono、灰色,带 **`⟠`** 前缀符号                                          | 如 "⟠ 已载入草稿…"    |
| 用户     | `log-user`    | 灰底气泡、`max-width: 88%`、右下角尖(`md md sm md`),500 字重,时间戳内联右侧            | 用户输入的指令        |
| AI       | `log-ai`      | 左对齐气泡、左下角尖(`md md md sm`);内含 `.ai-meta` + `.ai-body` + `.ai-acts`/`.ai-ok` | AI 返回的修改建议     |
| 生成中   | `log-pending` | 用文本字符 **`⟳`** + `spin 0.9s` 旋转,文案 **"正在处理…"**                             | 固定 **850ms** 后消失 |

**AI 气泡元信息** `.ai-meta`(mono 10px)三段:

| 段       | class       | 内容                                            |
| -------- | ----------- | ----------------------------------------------- |
| 角色     | `.ai-role`  | 黑底胶囊写 **"AI"**(9px / 700)                  |
| 文件目标 | `.ai-file`  | 文件目标,中点分隔(如 "正文 · 第 1 段"),溢出省略 |
| 时间     | `.log-time` | `HH:MM`                                         |

**文件目标**标注 AI 修改作用于文档何处:

- `正文 · 第 1 段` —— 替换指定段落
- `正文 · 末尾追加` —— 在文档末尾追加
- `标题` —— 修改文章标题
- `摘要` —— 生成摘要

### 应用后状态

点 **"应用"** 后,三按钮整块(`.ai-acts`)被替换为 `.ai-ok`(绿色 ✓ + 11px / 600 mono 文本,色 `--success`)。文案因操作而异:

| 文件目标 | `.ai-ok` 文案              |
| -------- | -------------------------- |
| 正文     | **"修改已写入文档"**       |
| 标题     | **"已应用新标题"**         |
| 摘要     | **"已复制到剪贴板(演示)"** |
| 默认     | **"已应用到文档"**         |

> [!important] 应用是单向操作
> 一旦应用,操作不可撤销,三按钮不再出现。

**忽略 / 重新生成**的行为:会从 `messages` 数组**物理删除**原消息后 re-render(不是隐藏)。

### 指令输入

- **斜杠命令**(内置 AI 操作):只对消息**首 token**(第一个空格前的部分)做字符串**全等匹配**。

  > [!info] 斜杠命令菜单
  > 输入 `/` 时**弹出命令建议菜单**(含 `/润色`、`/续写`、`/标题`、`/摘要` 及简要说明),支持键盘导航选择;选中后填入对应指令。匹配不上的指令仍落到 `custom`。

  | 命令    | 匹配     | 文件目标          | AI 回复前缀模板                                              |
  | ------- | -------- | ----------------- | ------------------------------------------------------------ |
  | `/润色` | polish   | `正文 · 第 1 段`  | `"改写后的第一段:\n\n" + 内容`                               |
  | `/续写` | continue | `正文 · 末尾追加` | `"为你续写的一段:\n\n" + 内容`                               |
  | `/标题` | title    | `标题`            | `"备选标题(示例):\n① …\n② …\n③ …"`(**固定 3 个候选**,带圈号) |
  | `/摘要` | summary  | `摘要`            | `"一句话摘要(示例):\n" + 内容`                               |
  | 其他    | custom   | `正文`            | `"收到指令,已按你的要求重新组织了表达,可以直接应用到正文。"` |

  **素材池游标步进**:每个命令有独立素材池(P1_POOL 3 条润色变体 / CONT_POOL 2 条续写 / TITLES 3 个 / SUMMARY 单条),重新生成会循环取下一条,游标 `{p1, ct, ti}` 持久化到 `localStorage["zd-wb-step"]`。无快捷键绑定到斜杠命令。

- **自由指令**:自然语言描述,走 `custom` 分支(如"把第二段改得更口语化")

### AI 产出的三个操作

每条 AI 返回的修改建议提供三个操作按钮:

| 操作         | 行为                                                     |
| ------------ | -------------------------------------------------------- |
| **忽略**     | 不采纳,气泡保留但标记                                    |
| **重新生成** | 让 AI 重新给一个版本                                     |
| **应用**     | 把修改写入右侧文档,显示"已应用到文档",内容区**高亮闪烁** |

> [!important] 核心交互
> "应用"是工作台的灵魂动作——AI 的修改**不直接改文档**,而是用户审阅后**主动应用**。这保证了人对内容的最终掌控。

### 辅助交互

- **新建对话**:清空当前对话日志
- **回到最新消息**:日志很长时跳到底部
- **添加附件**:上传图片等素材

### 底部状态栏

实时显示:

- **字数**
- **阅读时长**(如"约 2 分钟读完")

### 字数与阅读时长算法

`countWords()` 算法:

- **CJK 字符**(范围 `[\u4e00-\u9fff\u3000-\u303f\uff00-\uffef]`,含 CJK 标点与全角符号)按"一字一词"计
- **非 CJK** 按空白 `split` 计英文词数
- 公式:`总数 = cjk数 + 英文词数`

阅读时长:`Math.max(1, Math.round(n / 250))` —— **速率 250 字/分钟,最少 1 分钟**。

输出格式为单 span,中点分隔:**`"{n} 字 · 约 {mins} 分钟读完"`**。

## 自动保存

边写边存到 localStorage,不需要手动保存:

| 状态     | 显示           |
| -------- | -------------- |
| 输入中   | "正在保存…"    |
| 保存完成 | "已保存 HH:MM" |

可从 [[产品/功能/创作者中心#草稿箱|草稿箱]] 通过 `?draft=` 参数载入预置草稿。

## 写作配置

模型与模式**不是下拉、不是面板**,而是嵌在**对话输入框 `.sb-composer` 底部工具条 `.sb-tools`** 里的两个**胶囊小按钮**:

| 按钮 | class       | 默认         | 图标     | aria-label |
| ---- | ----------- | ------------ | -------- | ---------- |
| 模型 | `.sb-model` | **"GPT-4o"** | 星星 svg | "选择模型" |
| 模式 | `.sb-mode`  | **"创作"**   | 文件图标 | "切换模式" |

- **交互是"循环点击"**:`mi = (mi + 1) % MODELS.length`,每点一次跳下一个,**没有弹出菜单、没有高亮当前项**
- `MODELS = ["GPT-4o", "Claude 3.7", "DeepSeek-V3", "通义千问"]`
- `MODES = ["创作", "讨论", "深度"]`

> [!note] 模型清单
> 工作台默认模型清单与 [[产品/功能/账户与治理#设置|设置页]] 个性化保持一致(Claude 统一为 3.7)。默认模型可在设置页预设。

默认模型可在 [[产品/功能/账户与治理#设置|设置 → 个性化 → AI 写作助手]] 预设。

## 编辑模式(改已发布文章)

通过 `?edit=1` 参数进入编辑已发布文章:

- 顶部提示"**保存后将覆盖原稿**"
- 入口:帖子详情页的"编辑"按钮(仅作者可见,`?owner=1`)
- 保存覆盖原稿,不产生新版本

## 待办清单(todo)

左侧可折叠的卡片,管理本次写作的待办事项:

- 每项可勾选标记完成
- 带 **标签**:`正文` 或 `资料`
- 示例:"给第一段加一个钩子"、"补充播客平台链接"

## sidebar 底部用户卡

`.sidebar-user` 在对话面板底部,内容为:头像"我" + **"织云 用户"** + **"免费版"** + 设置齿轮。

> [!note] 信息冗余
> 此卡与顶栏头像菜单信息有冗余(顶栏显示"阿诚 / 认证作者",侧栏显示"织云 用户 / 免费版"),开发时需统一用户身份信息来源。

| draft id        | 内容                                |
| --------------- | ----------------------------------- |
| `draft-wb`      | 《一人公司生存指南…》               |
| `draft-podcast` | 《通勤路上听什么…》(当前默认页内容) |

## 移动端

两个断点:

| 断点     | 行为                |
| -------- | ------------------- |
| `1020px` | sidebar 300 → 260px |
| `760px`  | 完整移动模式        |

**760px 以下**:

- `.workbench` 改 `flex-direction: column`
- `.mode-tabs` 显示(46px 高,底部 2px 下划线指示当前),两 Tab:**"对话"**(终端图标)+ **"文档"**(文档图标)
- splitter 隐藏
- **移动端默认 Tab 是"文档"**(非对话),持久化到 `localStorage["zd-wb-pane"]`
- 单 pane 高度:`calc(100dvh - 60px - 48px - 46px)`
- 正文 `min-height: 60vh`

splitter 拖拽宽度范围 **240–480px**(桌面),持久化到 `localStorage["zd-wb-split"]`,移动端禁用。

## 状态机

| 状态                   | 触发                             | 表现                                                       |
| ---------------------- | -------------------------------- | ---------------------------------------------------------- |
| `busy` 全局标志        | AI 处理中(850ms)/ 发布中(1200ms) | 发送按钮 disabled、textarea disabled                       |
| AI 消息 `applied`      | 点"应用"                         | `true`,三按钮永久替换为 `.ai-ok`,不可逆                    |
| `jump-latest` 浮标三态 | —                                | 隐藏 / 显示(距底部 >80px)/ 有新消息(左侧 7px 黑点)         |
| 保存态                 | 输入                             | `"正在保存…"`(钟表 icon)→ 900ms → `"已保存 HH:MM"`(✓ icon) |
| 发布按钮 `.is-done`    | 发布成功                         | 变绿(`--success`)、文案"已发布"、`pointer-events` 锁死     |
| 正文 `ringflash`       | 应用 AI 后                       | 1.3s 动画,box-shadow 扩散                                  |

## 遗漏的全局模块

工作台页还包含全站通用的:通知浮窗(铃铛)、用户账户下拉、auth gate 强登录(未登录直接 `replace` 到 auth)。详见 [[全局规范]]。

## 业务规则

1. **AI 修改须经用户应用**:AI 不直接改文档,所有修改走"应用"动作
2. **应用有文件目标**:每次应用明确作用于标题/段落/末尾/摘要
3. **草稿自动持久化**:基于 localStorage,断网/刷新不丢内容
4. **模型可切换**:单次写作中可切换模型,影响后续 AI 调用
5. **编辑模式覆盖**:编辑已发布文章保存即覆盖,需谨慎(有提示)
6. **正文上限 5 万字**:超过 5 万字时阻止继续输入并提示,**不静默截断**
