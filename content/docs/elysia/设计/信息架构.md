# 信息架构

## 三端导航结构

### macOS

```
Home
├── Devices
│   └── [Device Name]
│       └── Workspaces
│           └── [Workspace Name]
│               └── Sessions
│                   └── [Session]
│                       ├── Conversation
│                       ├── Activity
│                       ├── Files
│                       ├── Diff
│                       └── Terminal
├── Settings
└── About
```

**V1 页面**：

| 页面 | 说明 |
|------|------|
| Home | Workspace 列表，快速进入最近 Session |
| Devices | 设备列表，显示在线状态 |
| Workspaces | 某个 Device 下的所有 Workspace |
| Sessions | 某个 Workspace 下的所有 Session 历史 |
| Session Detail | 核心页面：Conversation + Activity + Diff + Terminal |
| Settings | 模型选择、主题等 |
| About | 版本信息 |

---

### iOS

```
Devices
├── [Device Name]
│   └── Sessions
│       └── [Session]
│           ├── Activity
│           ├── Conversation
│           └── Detail
└── Settings
```

**V1 页面**：

| 页面 | 说明 |
|------|------|
| Devices | 设备列表，显示在线状态和当前 Session |
| Sessions | 某个 Device 的所有 Session |
| Session Detail | 查看 Activity + 发送消息 |
| Settings | 模型选择、通知等 |

**iOS 不做**：
- 复杂代码编辑器
- 文件树浏览
- 本地文件操作
- Terminal 界面

iOS 是 Agent Controller，不是 IDE。

---

### Web

```
Workspaces
├── [Workspace Name]
│   └── Sessions
│       └── [Session]
│           ├── Conversation
│           ├── Activity
│           ├── Diff
│           └── Terminal
└── Settings
```

**V1 页面**：

| 页面 | 说明 |
|------|------|
| Workspaces | Workspace 列表 |
| Session Detail | 核心页面，类似 Harness Web UI |
| Settings | 模型选择 |

**Web 可以独立完成**：
- 创建 Workspace（通过上传 zip 或 Git Clone）
- 创建 Session
- 发送消息
- 查看 Activity、Diff、Terminal
- 停止 / Continue Agent

---

## 页面层级

```text
Level 0: Devices / Workspaces（入口）
Level 1: Session（核心）
Level 2: Activity / Conversation / Diff / Terminal（Session 内部）
```

## 核心路径

```
创建 Workspace → 选择 Workspace → 创建 Session → Agent 执行 → 查看结果
```

最短路径：打开 App → 选择 Workspace → 输入任务 → 等待完成

---

## 导航模式

| 端 | 导航模式 | 说明 |
|----|---------|------|
| macOS | Sidebar + Content | 左侧导航树，右侧内容区 |
| iOS | Navigation Stack | 堆栈导航，符合 iOS 习惯 |
| Web | Top Nav + Content | 顶部导航 + 内容区 |

---

## 组件复用

三端共享的产品级组件（逻辑层）：
- Session 状态管理
- Agent Activity 渲染
- Diff 渲染
- Event 接收与处理
- Tool Execution 列表

三端独立的 UI 组件：
- 导航结构
- 布局样式
- 交互细节
