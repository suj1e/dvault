# Non-goals

本文档记录 V1 明确不做的功能、平台和场景。

这是产品决策，不是技术限制。以下全部是"现在不做"，不代表"永远不做"。

---

## 功能 Non-goals

### 口语练习

**不做**。V1 不提供口语练习功能（AI 对话、发音评测）。

口语练习需要复杂的 ASR（语音识别）和 TTS（语音合成）支持，以及发音评测算法。这些在 V1 之后考虑。

V1 只做口语的**记录**（用户标记自己说的好不好），不做练习。

### 社区互动

**不做**。V1 不提供用户之间的交流功能。

没有：
- 好友系统
- 动态 / 朋友圈
- 评论 / 点赞
- 组队学习
- 排行榜

### 母语者配对

**不做**。V1 不提供与母语者配对练习的功能。

### 直播课 / 视频课

**不做**。V1 不提供直播或录播课程。

### AI 深度批改

**不做**。V1 不提供作文逐句点评、语法深度分析。

V1 的写作反馈是**基础判分**：
- 是否正确回答题目
- 是否有拼写错误
- 是否包含关键词

不提供：
- 语法错误详细解释
- 句式优化建议
- 地道表达推荐

### 个性化内容推荐

**不做**。V1 不基于 AI 生成个性化学习内容。

内容是**预设 + 用户导入**，不是 AI 动态生成。

### 游戏化系统

**不做**。V1 不提供积分、徽章、排行榜等游戏化元素。

V1 保持学习严肃性，用**进度可视化**替代游戏化激励。

### 成就系统

**不做**。V1 不提供成就、徽章、证书等。

### 学习计划定制

**不做**。V1 不提供 AI 生成的学习计划。

用户自己决定学什么、怎么学。App 提供工具，不提供计划。

### 单词游戏

**不做**。V1 不提供拼写游戏、配对游戏、消消乐等。

词汇学习通过**SRS 闪卡**完成，不是游戏。

### 语法专项练习

**不做**。V1 不提供语法专项练习。

语法通过**阅读中的上下文**和**错误分析**间接学习，不是独立模块。

### 真题 / 考试模拟

**不做**。V1 不提供托福、雅思、GRE 等考试真题。

### 离线词典

**不做**。V1 不提供离线词典查询。

查词通过**内置词库 + 网络查询**完成。

### 翻译功能

**不做**。V1 不提供整句翻译、实时翻译。

---

## 平台 Non-goals

### Web 端

**不做**。V1 只有 iOS 端。

Web 端在 V1 之后考虑。

### Android 端

**不做**。V1 不开发 Android App。

移动端只做 iOS。

### 桌面端

**不做**。V1 不开发 macOS / Windows 桌面端。

### 手表端

**不做**。V1 不开发 Apple Watch 端。

---

## 商业 Non-goals

### 账户系统

**不做**。V1 不要求用户注册或登录。

设备即身份。用户直接使用，无需账户。

### 订阅 / 付费

**不做**。V1 不涉及付费功能。

V1 是免费产品，后续商业化策略不在 V1 范围内。

### 广告

**不做**。V1 不展示广告。

### 内容市场

**不做**。V1 不建立内容交易市场。

---

## 为什么这些不做

V1 的核心目标是：

> **让语言学习真正发生变化，从"背了忘"变成"学了用"。**

所有 Non-goals 的共同特征：它们要么增加了复杂度但没有直接服务于学习闭环，要么可以在形成闭环之后再通过更新添加。

V1 的时间应该花在：
1. 学习闭环的流畅性
2. 内容的深度和质量
3. 反馈机制的准确性
4. 进度可视化的清晰度

而不是花在：
- 设计游戏化系统
- 实现口语评测
- 构建社区生态
- 规划商业化

---

> [!warning] 一个常见的陷阱
> "先做了，后面再删" 是产品设计的毒药。每一个 Non-goal 都应该被**主动拒绝**，而不是"来不及做"。
