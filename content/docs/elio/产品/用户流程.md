## Story 1：新用户首次使用

**角色**：英语学习者，有一定基础  
**设备**：iOS App

1. 用户下载 Elio，打开 App
2. 选择要学习的语言（英语）
3. 设置当前水平和学习目标（如"提升商务英语"）
4. App 推荐初始内容：
   - 5 个核心词汇
   - 1 篇入门阅读
   - 1 段听力材料
5. 用户开始第一次学习
6. 完成学习后，App 记录初始进度

**关键页面**：Welcome → 选择语言 → 设定目标 → 推荐内容 → 开始学习

## Story 2：词汇学习流程

**角色**：语言学习者  
**设备**：iOS App

1. 用户进入词汇学习模块
2. App 根据 SRS 算法展示今日待复习词汇
3. 用户看到单词，思考释义
4. 用户点击"显示答案"
5. 用户自评掌握程度：
   - "忘记了" → 缩短复习间隔
   - "有点犹豫" → 保持间隔
   - "记得很清楚" → 延长复习间隔
6. App 记录本次复习，更新 SRS 计划
7. 完成 20 个词汇后，显示本轮总结

**关键页面**：词汇模块 → 闪卡 → 自评 → 总结

## Story 3：阅读学习流程

**角色**：英语学习者  
**设备**：iOS App

1. 用户选择阅读练习
2. App 推荐适合当前水平的文章
3. 用户阅读文章
4. 遇到生词，点击查词：
   - 显示释义、音标、例句
   - 自动加入生词本
5. 阅读完成后，完成练习题：
   - 选择题（理解判断）
   - 填空题（关键词）
6. App 判分并记录错误
7. App 分析错误类型，更新薄弱点

**关键页面**：阅读模块 → 文章列表 → 阅读器 → 练习题 → 结果分析

## Story 4：听力学习流程

**角色**：英语学习者  
**设备**：iOS App

1. 用户选择听力练习
2. App 推荐适合当前水平的听力材料
3. 用户播放音频，同步看字幕
4. 用户完成听力理解题
5. App 判分并记录错误
6. 用户可以反复听难点部分

**关键页面**：听力模块 → 材料列表 → 播放器 → 练习题

---

## Story 5：写作练习流程

**角色**：英语学习者  
**设备**：iOS App

1. 用户选择写作练习
2. App 给出写作题目（如"用 3-5 句话描述今天的工作"）
3. 用户输入答案
4. App 提供基础反馈：
   - 拼写错误
   - 语法错误（基础）
   - 是否覆盖主题要点
5. App 记录错误类型
6. 用户查看正确答案示例

**关键页面**：写作模块 → 题目 → 输入 → 反馈 → 示例

## Story 6：每日学习流程

**角色**：自我驱动型学习者  
**设备**：iOS App

1. 用户打开 Elio
2. Home 页显示今日学习状态：
   - 连续学习天数
   - 今日已学习时长
   - 今日目标完成度
   - 待复习词汇数
3. 用户点击"开始今日学习"
4. App 按优先级推荐今日任务：
   - 优先：SRS 复习
   - 其次：新内容学习
   - 可选：薄弱点强化
5. 用户完成任务，进度更新
6. 完成目标后，显示鼓励信息

**关键页面**：Home → 今日任务 → 练习 → 完成

## Story 7：生词本管理

**角色**：英语学习者  
**设备**：iOS App

1. 用户在阅读中遇到生词，点击查词
2. 词被自动加入生词本
3. 用户可以在生词本中：
   - 查看所有生词
   - 编辑释义
   - 标记已掌握
   - 批量导出
4. 生词自动进入 SRS 复习队列
5. 用户复习时，App 优先展示生词本中的词汇

**关键页面**：生词本 → 词列表 → 查词 → 复习

---

## Story 8：进度查看

**角色**：自我驱动型学习者  
**设备**：iOS App

1. 用户进入进度页面
2. 查看各维度掌握度：
   - 词汇：75%
   - 阅读：60%
   - 听力：45%
   - 写作：30%
3. 查看学习趋势：
   - 过去 7 天学习时长
   - 正确率变化
   - 新增词汇数
4. 查看薄弱点：
   - 高频错误类型
   - 需要强化的技能
5. App 给出学习建议：
   - "最近听力正确率下降，建议增加听力练习"
   - "以下 10 个词汇需要复习"

**关键页面**：进度 → 掌握度 → 趋势 → 建议

## 核心学习闭环

```text
理解（阅读 / 听力）
    ↓
遇到生词 → 查词 → 加入生词本 → SRS 复习
    ↓
练习（词汇 / 阅读 / 听力 / 写作）
    ↓
获得反馈（判分 + 错误记录）
    ↓
更新进度（掌握度 + 薄弱点）
    ↓
推荐下一步（基于掌握度自适应）
    ↓
回到理解
```

---

## SRS 算法（简化版）

```text
新词
  → 第一次复习：1 天后
  → 第二次复习：3 天后
  → 第三次复习：7 天后
  → 第四次复习：14 天后
  → 第五次复习：30 天后
  → 标记为"已掌握"

用户自评影响间隔：
  - "忘记了"：间隔 × 0.5
  - "有点犹豫"：间隔 × 1
  - "记得很清楚"：间隔 × 2
```

## 用户介入点

| 时机 | 用户操作 | 系统行为 |
|------|---------|---------|
| 学习时 | 点击查词 | 记录生词，加入生词本 |
| 复习时 | 自评掌握程度 | 调整 SRS 间隔 |
| 练习后 | 查看错误分析 | 了解薄弱点 |
| 每日 | 查看进度 | 调整学习重点 |
| 需要时 | 手动添加词汇 | 补充生词本 |

## 失败处理

### 词汇遗忘

- 用户标记"忘记了"
- 词汇回到 SRS 队列，缩短间隔
- 连续 3 次忘记，标记为"困难词"，增加复习频率

### 连续未学习

- Streak 中断
- App 显示鼓励信息，建议从少量开始
- 不惩罚，保持学习动力

### 进度停滞

- 正确率下降 → 推荐回退到更简单的内容
- 学习时长不足 → 提醒调整目标
- 词汇复习积压 → 优先清理复习队列
