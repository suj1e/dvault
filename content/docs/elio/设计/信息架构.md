# 信息架构

## 核心导航结构

```
Home（今日学习）
├── 今日任务
├── 连续学习天数
├── 学习进度
└── 快速开始

Discover（发现）
├── 阅读
├── 听力
├── 词汇
└── 写作

Library（图书馆）
├── 我的文章
├── 我的词汇
├── 生词本
└── 导入内容

Progress（进度）
├── 掌握度
├── 学习趋势
├── 错误记录
└── 薄弱点

Settings（设置）
├── 语言管理
├── 学习目标
├── 通知
└── 关于
```

---

## 核心页面

### Home

**入口页面**。显示今日学习状态和任务。

| 组件 | 说明 |
|------|------|
| Streak | 连续学习天数，带动画效果 |
| 今日进度 | 已学习时长 / 目标时长 |
| 待复习词汇 | SRS 复习队列数量 |
| 快速开始 | 一键开始今日推荐学习 |
| 继续学习 | 返回上次中断的内容 |

### Discover

**内容发现页面**。浏览和选择学习内容。

| 子页面 | 说明 |
|--------|------|
| 阅读 | 文章列表，按难度和主题分类 |
| 听力 | 音频列表，带字幕 |
| 词汇 | 词汇闪卡，SRS 复习 |
| 写作 | 写作题目列表 |

### Library

**个人图书馆**。管理用户的内容和词汇。

| 子页面 | 说明 |
|--------|------|
| 我的文章 | 用户收藏或上传的文章 |
| 我的词汇 | 用户收集的词汇 |
| 生词本 | 学习中遇到的生词 |
| 导入内容 | 导入网页、文章等外部内容 |

### Progress

**进度页面**。展示学习数据和进步。

| 子页面 | 说明 |
|--------|------|
| 掌握度 | 各技能维度的掌握度 |
| 学习趋势 | 过去 7/30/90 天的学习数据 |
| 错误记录 | 所有错误的历史记录 |
| 薄弱点 | 需要强化的技能和词汇 |

### Settings

**设置页面**。

| 子页面 | 说明 |
|--------|------|
| 语言管理 | 添加 / 暂停 / 删除语言 |
| 学习目标 | 每日学习时长目标 |
| 通知 | 学习提醒 |
| 关于 | 版本信息 |

---

## 页面层级

```text
Level 0: Home / Discover / Library / Progress / Settings（Tab Bar）
Level 1: 内容列表、词汇列表、文章详情
Level 2: 练习页面、阅读器、播放器
```

---

## 核心路径

```
打开 App → Home → 开始学习 → 练习 → 获得反馈 → 查看进度 → 继续学习
```

最短路径：打开 App → 点击"开始学习" → 完成练习 → 返回 Home

---

## 导航模式

| 组件 | 模式 | 说明 |
|------|------|------|
| Tab Bar | 底部标签栏 | 5 个主要模块 |
| Navigation | 堆栈导航 | 子页面推入 |
| Modal | 模态呈现 | 查词、设置等轻量操作 |

---

## 关键交互

### 查词

用户在阅读中遇到生词，点击单词：

```text
阅读器
  ↓ 点击单词
查词弹窗
  ├── 释义
  ├── 音标
  ├── 例句
  ├── 发音播放
  └── "加入生词本"按钮
```

### 练习

用户进入练习模式：

```text
练习页
  ↓
显示题目
  ↓
用户作答
  ↓
提交
  ↓
即时反馈（正确 / 错误 + 解析）
  ↓
记录错误
  ↓
下一题
  ↓
本轮总结
```

### 进度查看

用户查看学习进度：

```text
Progress 页
  ↓
掌握度总览
  ↓
各技能详情
  ↓
错误记录
  ↓
薄弱点分析
  ↓
学习建议
```
