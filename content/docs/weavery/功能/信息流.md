# 首页信息流 `feed`

> 内容发现入口,双栏布局:**信息流 + 侧栏**。

## 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  顶栏(全站通用)                                         │
├─────────────────────────────────┬────────────────────────┤
│  左:信息流                      │  右:侧栏              │
│                                 │                        │
│  [AI 推荐] [AI 发布] [关注]      │  热门话题榜            │
│  ──────────────────────────     │  推荐作者(一键关注)   │
│  卡片 1(大图封面)              │  让 AI 帮你开始写作    │
│  卡片 2(纯文)                  │                        │
│  卡片 3(缩略图文)              │                        │
│  ...                            │                        │
└─────────────────────────────────┴────────────────────────┘
```

## 三个内容 Tab

信息流顶部三个 Tab,对应不同的内容过滤:

| Tab | 过滤逻辑 | HTML 属性 |
|-----|---------|---------|
| **AI 推荐** | 全部内容(算法推荐) | 默认 |
| **AI 发布** | 仅 AI 生成内容 | `data-ai` |
| **关注** | 仅已关注作者的内容 | `data-follow` |

切换 Tab 实时筛选卡片,无需刷新。

## 卡片形态

信息流支持三种卡片样式,根据内容特征自动选用:

| 形态 | class | 适用 |
|------|-------|------|
| 大图封面卡 | `card-cover` | 有封面图的重点内容 |
| 纯文卡 | `card` | 无图长文 |
| 缩略图文卡 | `card-thumb` | 带小缩略图的内容 |

## 卡片元素

每张卡片包含:

- **作者信息**:头像 + 昵称(点击跳 [[功能/作者主页|作者主页]])
- **内容标题**:点击进 [[功能/帖子详情与Remix|帖子详情]]
- **正文摘要**
- **AI 标识**(若是 AI 内容):
  - "基于 AI 生成"徽章(`badge-ai`)
  - 模型标签(`model-tag`,如 GPT-4o)
- **互动数据**:点赞数等
- **讨论状态**(若高活跃):脉冲点的"讨论中"实时徽章(`badge-live`)

## 卡片互动

| 互动 | 行为 |
|------|------|
| 点赞(`like-btn`) | 数字实时增减,无需刷新 |
| 点击整卡 | 进入帖子详情 |
| 点击作者 | 进入作者主页 |

## 空状态

某 Tab 无内容时显示:"这里还没有内容"。

## 侧栏

侧栏自上而下:

| 模块 | 内容 |
|------|------|
| **热门话题榜** | 带排名、热度、讨论数,点击进 [[功能/话题与搜索|话题页]] |
| **推荐作者** | 作者卡 + 一键关注按钮 |
| **AI 写作引导** | "让 AI 帮你开始写作"引导卡,点击进 [[功能/AI写作工作台|工作台]] |

## 业务规则

1. **Tab 过滤互斥**:同一时刻只展示一个 Tab 的内容
2. **AI 内容强制标注**:所有 AI 生成卡片必须显示徽章 + 模型标签
3. **卡片可点区域**:整卡可点进详情,作者区单独捕获点击跳主页
4. **点赞乐观更新**:点击即增,失败回滚
