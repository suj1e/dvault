# AI 写作工作台 `create`

> weavery 的核心。双栏布局:**左侧 AI 对话 + 右侧文档**,AI 把修改直接写入文档。

工作台是整个产品的创作枢纽,被首页侧栏、话题页"发帖"、帖子页"编辑/放入工作台/Remix"、草稿箱等多处入口指向(见 [[信息架构]])。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  顶栏(全站通用)                                        │
├──────────────────────┬──────────────────────────────────┤
│  左栏:AI 对话面板    │  右栏:文档区                     │
│                      │                                  │
│  ┌─ 待办(可折叠)──┐ │  标题输入框                       │
│  │ ☐ 给第一段加钩子│ │  ──────────────                  │
│  │ ☐ 补充播客链接  │ │  正文 textarea(Markdown)         │
│  └──────────────────┘ │                                  │
│                      │  工具栏:加粗/斜体/引用/列表/    │
│  对话日志:           │          链接/插图               │
│  [我] 帮我润色第一段 │                                  │
│  [AI] (修改建议)     │  底部:字数 · 约 N 分钟读完       │
│   [忽略][重新生成]   │        [发布]                    │
│   [应用]             │                                  │
│                      │                                  │
│  输入框 + /命令      │                                  │
└──────────────────────┴──────────────────────────────────┘
```

- **桌面**:左右双栏,中间可拖拽 **splitter** 调整栏宽
- **移动**:切换为"对话 / 文档" Tab 单栏显示

## 左栏:AI 对话面板

### 对话日志

聊天气泡式,按角色区分:

| 角色 | 样式 | 内容 |
|------|------|------|
| 用户(`log-user`) | 右对齐气泡 | 用户输入的指令 |
| AI(`log-ai`) | 左对齐气泡 | AI 返回的修改建议,带角色标签"AI"与**文件目标** |

**文件目标**标注 AI 修改作用于文档何处:
- `正文 · 第 1 段` —— 替换指定段落
- `正文 · 末尾追加` —— 在文档末尾追加
- `标题` —— 修改文章标题
- `摘要` —— 生成摘要

### 指令输入

- **斜杠命令**(内置 AI 操作):

  | 命令 | 作用 |
  |------|------|
  | `/润色` | polish —— 优化现有文字表达 |
  | `/续写` | continue —— 顺着当前内容继续写 |
  | `/标题` | title —— 生成/优化标题 |
  | `/摘要` | summary —— 生成文章摘要 |

- **自由指令**:自然语言描述,走 `custom` 分支(如"把第二段改得更口语化")

### AI 产出的三个操作

每条 AI 返回的修改建议提供三个操作按钮:

| 操作 | 行为 |
|------|------|
| **忽略** | 不采纳,气泡保留但标记 |
| **重新生成** | 让 AI 重新给一个版本 |
| **应用** | 把修改写入右侧文档,显示"已应用到文档",内容区**高亮闪烁** |

> [!important] 核心交互
> "应用"是工作台的灵魂动作——AI 的修改**不直接改文档**,而是用户审阅后**主动应用**。这保证了人对内容的最终掌控。

### 辅助交互

- **新建对话**:清空当前对话日志
- **回到最新消息**:日志很长时跳到底部
- **添加附件**:上传图片等素材

## 自动保存

边写边存到 localStorage,不需要手动保存:

| 状态 | 显示 |
|------|------|
| 输入中 | "正在保存…" |
| 保存完成 | "已保存 HH:MM" |

可从 [[功能/创作者中心#草稿箱|草稿箱]] 通过 `?draft=` 参数载入预置草稿。

## 写作配置

工作台顶部/侧边可配置:

| 配置 | 选项 |
|------|------|
| **模型切换** | GPT-4o / Claude 4 / DeepSeek-V3 / 通义千问 |
| **写作模式** | 创作 / 讨论 / 深度 |

默认模型可在 [[功能/账户与治理#设置|设置 → 个性化 → AI 写作助手]] 预设。

## 发布

| 操作 | 效果 |
|------|------|
| 点击「发布」 | 按钮变绿显示"已发布",Toast 提示"文章已发布" |

发布后文章进入 [[功能/信息流|信息流]] 和作者主页。

## 编辑模式(改已发布文章)

通过 `?edit=1` 参数进入编辑已发布文章:

- 顶部提示"**保存后将覆盖原稿**"
- 入口:帖子详情页的"编辑"按钮(仅作者可见,`?owner=1`)
- 保存覆盖原稿,不产生新版本

## 待办清单(todo)

左侧可折叠的卡片,管理本次写作的待办事项:

- 每项可勾选标记完成
- 带 **标签**:`正文` 或 `资料`
- 示例:"给第一段加一个钩子"、"补充播客平台链接"

## 业务规则

1. **AI 修改须经用户应用**:AI 不直接改文档,所有修改走"应用"动作
2. **应用有文件目标**:每次应用明确作用于标题/段落/末尾/摘要
3. **草稿自动持久化**:基于 localStorage,断网/刷新不丢内容
4. **模型可切换**:单次写作中可切换模型,影响后续 AI 调用
5. **编辑模式覆盖**:编辑已发布文章保存即覆盖,需谨慎(有提示)
