# 数据模型

## 核心数据结构

### Language

```yaml
Language:
  id: string (UUID)
  code: string (en / ja / fr / de / es / ko ...)
  name: string (英语 / 日语 / 法语 ...)
  level: string (A1 / A2 / B1 / B2 / C1 / C2)
  goal: string | null
  status: "active" | "paused"
  startedAt: timestamp
  createdAt: timestamp
```

### Skill

```yaml
Skill:
  id: string (UUID)
  languageId: string (所属语言)
  type: "vocabulary" | "reading" | "listening" | "writing" | "speaking"
  level: string (A1 / A2 / B1 / B2 / C1 / C2)
  mastery: number (0-100)
  exerciseCount: number
  correctRate: number (0-100)
  updatedAt: timestamp
```

### Exercise

```yaml
Exercise:
  id: string (UUID)
  languageId: string (所属语言)
  skillId: string (所属技能)
  type: "vocab_review" | "reading" | "listening" | "writing" | "expression"
  content: object (练习内容)
  userAnswer: string | null
  correctAnswer: string | null
  isCorrect: boolean | null
  duration: number (秒)
  errors: Error[]
  createdAt: timestamp
```

### Vocabulary

```yaml
Vocabulary:
  id: string (UUID)
  languageId: string (所属语言)
  word: string
  definition: string
  pronunciation: string | null
  example: string | null
  level: string (词汇等级)
  source: "builtin" | "user" | "imported"
  nextReviewAt: timestamp (SRS)
  reviewCount: number
  mastery: number (0-100)
  createdAt: timestamp
  updatedAt: timestamp
```

### Content

```yaml
Content:
  id: string (UUID)
  languageId: string (所属语言)
  type: "article" | "video" | "audio"
  title: string
  body: string | null (文章内容)
  sourceUrl: string | null
  difficulty: string (Lv1 / Lv2 / Lv3 / Lv4 / Lv5)
  tags: string[]
  createdAt: timestamp
```

### Progress

```yaml
Progress:
  id: string (UUID)
  languageId: string (所属语言)
  streak: number (连续天数)
  totalStudyTime: number (秒)
  totalExercises: number
  averageAccuracy: number (0-100)
  masteryMap:
    vocabulary: number
    reading: number
    listening: number
    writing: number
    speaking: number
  weakPoints: string[] (薄弱技能 ID 列表)
  updatedAt: timestamp
```

### Error

```yaml
Error:
  id: string (UUID)
  languageId: string (所属语言)
  skillId: string (所属技能)
  type: "spelling" | "grammar" | "comprehension" | "pronunciation" | "expression"
  content: string (错误内容)
  correctContent: string (正确内容)
  context: string | null
  occurrences: number
  lastOccurredAt: timestamp
  createdAt: timestamp
```

## 存储方案

### V1 本地存储

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| Language 列表 | `UserDefaults` | 语言配置 |
| Skill 数据 | `CoreData` | 技能进度 |
| Exercise 记录 | `CoreData` | 练习历史 |
| Vocabulary | `CoreData` | 词汇库 |
| Content | `CoreData` | 学习内容 |
| Progress | `CoreData` | 进度汇总 |
| Error | `CoreData` | 错误记录 |

### V1 不存储

- 音频 / 视频文件（内置资源 Bundle）
- 大段文本内容（内置或用户导入后本地存储）
- 用户 Profile
- 云端数据

## 数据流

```text
User Practice
  → Exercise Created
    → Error Recorded (if any)
      → Progress Updated
        → Skill Mastery Updated
          → Next Exercise Recommended
```

## 状态机

### Language 状态

```
active ←→ paused
```

用户随时可以暂停或恢复语言学习。

### Exercise 状态

```
pending → completed (correct | incorrect)
```

### SRS 状态

```
new → learning → reviewing → mastered
  ↓          ↓           ↓
间隔递增    间隔递增     间隔很长
```

## 关键计算

### 掌握度计算

```text
mastery = (正确练习数 / 总练习数) × 100
```

### SRS 间隔

```text
Level 0 (新词): 1 天
Level 1: 2 天
Level 2: 4 天
Level 3: 7 天
Level 4: 14 天
Level 5: 30 天
Level 6: 已掌握
```

用户自评调整：
- "忘记了"：间隔 × 0.5，降级
- "有点犹豫"：间隔 × 1，保持
- "记得很清楚"：间隔 × 2，升级

### Streak 计算

```text
连续学习天数 = 连续有练习记录的日历天数

中断条件：
- 自然日 0:00 后没有练习记录
- 用户主动重置
```
