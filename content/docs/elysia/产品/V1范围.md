# V1 范围

## V1 完整闭环

```text
User
  ↓
Client（macOS / iOS / Web）
  ↓
Session
  ↓
Agent
  ↓
Tool Execution（read / write / list / search / run）
  ↓
Workspace
  ↓
Execution（本地）
  ↓
Verification（Agent 自检 + 测试运行）
  ↓
Events
  ↓
Clients（实时更新）
```

V1 的目标是**形成完整闭环**，而不是堆功能。

## V1 模型决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 执行环境 | macOS 本地 | 本地文件系统访问最安全，延迟最低 |
| 多端访问 | 同一 Session 多端观察 | 核心差异点，V1 必须体现 |
| 模型选择 | V1 提供预设选项 | 不需要用户自行配置 API Key |
| Workspace 管理 | 本地文件夹 | 简单直接，V1 不做云端同步 |
| Session 存储 | 本地 + 云端索引 | 历史可查，但执行在本地 |

## V1 不做什么的底线

> **V1 必须形成完整闭环，而不是堆功能。**

如果某个功能不影响闭环形成，且不直接服务于"Agent 真正动手改代码"，就应该被推迟。

判断标准：
1. 这个功能是否直接服务于 Agent 执行 Task？
2. 没有这个功能，Agent 能否完成一个完整的 Coding Task？
3. 这个功能是否可以在 V1 之后通过更新添加？

如果三个答案都是"否 → 是 → 是"，那么它属于 V1。否则推迟。
