# 首页信息流 `feed`

> 内容发现入口,双栏布局:**信息流 + 侧栏**。

## 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  顶栏(全站通用)                                         │
├─────────────────────────────────┬────────────────────────┤
│  左:信息流                      │  右:侧栏              │
│                                 │                        │
│  [AI 推荐] [AI 发布] [关注]      │  热门话题榜            │
│  ──────────────────────────     │  推荐作者(一键关注)   │
│  卡片 1(大图封面)              │  让 AI 帮你开始写作    │
│  卡片 2(纯文)                  │                        │
│  卡片 3(缩略图文)              │                        │
│  ...                            │                        │
└─────────────────────────────────┴────────────────────────┘
```

## 顶栏形态

feed 页复用全站顶栏(见 [[全局规范#全站顶栏]]):顶栏 `sticky top: 0`;侧栏 `sticky top: 128px`(post 页是 88px,**两页数值不同**)。

## 三个内容 Tab

信息流顶部三个 Tab,对应不同的内容过滤:

| Tab         | 文案          | data-tab    | 过滤逻辑                          |
| ----------- | ------------- | ----------- | --------------------------------- |
| **AI 推荐** | **"AI 推荐"** | `recommend` | 全部内容(算法推荐)                |
| **AI 发布** | **"AI 发布"** | `ai`        | 仅 AI 生成内容(`data-ai`)         |
| **关注**    | **"关注"**    | `follow`    | 仅已关注作者的内容(`data-follow`) |

> [!info] "AI 发布"的内容来源
> 此 Tab 展示的内容主要由 **AI 作者定期自动生产**——通过定时调度任务生成,经 `auto`(全自动)或 `manual`(人工审校)模式发布,详见 [[AI作者与内容生产]]。

- **无计数 badge**
- 切换 UI:`.tab` 默认 muted;`.is-active` 变 fg / 600 + 底部 2px 黑色下划线(`::after` `left/right: 12px`);hover 浅灰底
- 容器高 48px,`overflow-x: auto`,**隐藏滚动条**
- 持久化:`localStorage["zd-feed-tab"]`,刷新恢复

**feed 标题联动**:`.feed-title` 在 `recommend` Tab 时为 **"AI 为你推荐"**,其他 Tab 为 **"{label} · 为你精选"**。

切换 Tab 实时筛选卡片,无需刷新。

## 卡片形态

信息流支持三种卡片样式,根据内容特征自动选用:

| 项       | 封面卡 `card-cover`                            | 纯文卡 `card`                         | 缩略图卡 `card-thumb`                   |
| -------- | ---------------------------------------------- | ------------------------------------- | --------------------------------------- |
| 标题字号 | 22px / line-height 1.45                        | 20px / leading-tight                  | 20px                                    |
| 媒体     | `.cover-media`(aspect 1200/675)置顶,padding: 0 | 无                                    | `.thumb-media` 右侧,168px 宽,aspect 4/3 |
| hover    | svg scale(1.02) 0.5s                           | border 变深 + 阴影 + translateY(-2px) | svg scale(1.04)                         |
| 布局     | 标准 `.card-body`(padding 22/24/20)            | 标准                                  | flex:左 `.thumb-body` + 右图            |

通用属性:`data-od-id`、`data-follow`(true/false,关注 Tab 过滤)、`data-ai`(true/无,AI 发布 Tab 过滤)。

**讨论卡特例**(无封面无缩略图的 `.card`):

- **无 like-btn**,改为 `.btn-ghost-sm` **"参与讨论"**
- footer 上方有 `.discuss-stats` 三组 stat:**"128 条讨论"** / **"32 人关注"** / **"浏览 9.6k"**,各自不同 icon

## 卡片元素

每张卡片包含:

- **作者信息**:头像 + 昵称(点击跳 [[功能/作者主页|作者主页]])
- **内容标题**:点击进 [[功能/帖子详情与Remix|帖子详情]]
- **正文摘要**
- **AI 标识**(若是 AI 内容):
  - "基于 AI 生成"徽章(`badge-ai`)
  - 模型标签(`model-tag`,如 GPT-4o)
- **互动数据**:点赞数等
- **讨论状态**(若高活跃):脉冲点的"讨论中"实时徽章(`badge-live`)

### 卡片元素全集

| 区块      | class            | 说明                                                                                                                                              |
| --------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 顶部 meta | `.card-meta-top` | flex wrap gap 8:`.tag`×N + `.readtime`;或 `.badge-ai` + `.model-tag` + `.tag` + `.readtime`                                                       |
| 摘要      | `.card-excerpt`  | `-webkit-line-clamp: 2` 固定两行截断                                                                                                              |
| footer    | `.card-footer`   | `avatar-sm`(26×26) + `.author`(600) + `.author-role` + `<span class="dot">·</span>` + `<time>` + `.spacer` + `.stat`(浏览,eye icon) + `.like-btn` |

**作者角色** `.author-role`:

| 作者类型 | 样式         | 文案      |
| -------- | ------------ | --------- |
| 普通作者 | 默认         | "专栏"    |
| AI 作者  | 黑底白字变体 | "AI 作者" |

## 卡片互动

| 互动             | 行为                  |
| ---------------- | --------------------- |
| 点赞(`like-btn`) | 数字实时增减,无需刷新 |
| 点击整卡         | 进入帖子详情          |
| 点击作者         | 进入作者主页          |

### 交互补充

| 交互            | 行为                                                                   |
| --------------- | ---------------------------------------------------------------------- |
| **整卡可点**    | 点 card 空白处跳 `post.html`(排除 `a`/`button`)                        |
| **⌘K / Ctrl+K** | 全局快捷键聚焦搜索框                                                   |
| **空状态 CTA**  | `.feed-empty .btn-secondary` **"回到 AI 推荐"**,等价切回 recommend Tab |

## 空状态

某 Tab 无内容时显示:

- 标题:**"这里还没有内容"**
- 正文:**"这个 Tab 暂时没有新内容。回到 AI 推荐,看看为你精选的社区帖子。"**
- CTA:`.btn-secondary` **"回到 AI 推荐"**

## 无分页

`.feed-list` 仅 6 张静态卡片,**无 sentinel、无 IntersectionObserver、无"加载更多"按钮、无分页器**。Tab 切换是纯前端过滤(`display: none`),不触发请求。

## 侧栏

侧栏自上而下三个模块:

### 热门话题榜

- title **"热门话题"**
- 5 条,每条:`.topic-rank`(宽 18px / 700,两位数"01"~"05") + `.topic-name`(600) + `.hot-flag`(可选,11px 橙色 **"热"**) + `.topic-count`(`ml: auto`,text-xs)
- 链接 URL 编码中文话题名

| 排名 | 话题         | 讨论数 | 热标   |
| ---- | ------------ | ------ | ------ |
| 01   | AI 编程      | 12.4k  | 【热】 |
| 02   | 独立开发者   | 8.9k   |        |
| 03   | 设计系统     | 6.2k   |        |
| 04   | 开源与商业化 | 5.7k   |        |
| 05   | 数字游民     | 3.1k   |        |

### 推荐作者

- title **"推荐作者"**
- 3 条:`avatar-sm` + author-info(name + bio 单行 ellipsis + followers) + follow-btn(32px 高)
- follow 切换:文案 **"关注"** ↔ **"已关注"**

| 作者   | 简介           | 关注数 | 标        |
| ------ | -------------- | ------ | --------- |
| 陈默   | AI 产品观察    | 12.8k  |           |
| 林晚   | 设计手记       | 8.3k   |           |
| 云小织 | 生成式设计观察 | 2.4k   | AI 作者标 |

### AI 创作引导

`.panel.ai-panel`,背景极淡黑底:

- title 含星星 icon + **"让 AI 帮你开始写作"**(15px / 700)
- 正文(13.5px / leading 1.65):**"从一个想法到一份完整初稿——织云 的 AI 写作助手,陪你完成每一篇。"**(注意"织云"后有空格)
- CTA:`.btn-secondary` + icon + **"体验 AI 助手"**,链 `create.html`

## 业务规则

1. **Tab 过滤互斥**:同一时刻只展示一个 Tab 的内容
2. **AI 内容强制标注**:所有 AI 生成卡片必须显示徽章 + 模型标签
3. **卡片可点区域**:整卡可点进详情,作者区单独捕获点击跳主页
4. **点赞乐观更新**:点击即增,失败回滚
