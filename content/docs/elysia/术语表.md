# 术语表

## A

### Agent

AI 实体，能够理解任务、调用 Tool、执行操作、验证结果。

在 Elysia 中，Agent 是产品的核心，不是附加功能。

### Agent Activity

Agent 执行过程中产生的所有操作记录，包括：
- Agent 的思考过程
- Tool 调用记录
- 文件变更
- 命令执行

### Agent Loop

Agent 的基本工作循环：Understand → Plan → Act → Observe → Verify → Complete / Continue

---

## D

### Device

能执行 Coding Agent 的计算设备。

在 Elysia 中，Device 是一等公民，是产品模型的核心概念。

V1 支持 macOS，未来支持 Linux。

### Diff

文件修改的对比视图，显示 Agent 修改了什么内容。

---

## E

### Event

系统状态变化的通知。用于多端同步和实时 UI 更新。

Elysia 使用 Event System 让三个客户端（macOS / iOS / Web）保持状态一致。

### Execution

Agent 调用 Tool 实际操作 Workspace 的过程。

Elysia 的 Execution 是真实的：Agent 真的读写文件、真的执行命令、真的运行测试。

---

## M

### Multi-device

多设备支持。同一个 Session 可以在多个 Device 上查看和控制。

这是 Elysia 的核心差异点。

---

## S

### Session

用户与 Agent 持续交互的核心对象。

一个 Session 包含：
- 任务描述
- Agent 执行过程
- 所有 Tool 调用
- 所有消息
- 执行结果

Session 可以被 Resume（重新执行）。

---

## T

### Task

Session 中用户给出的具体任务描述。

V1 中一个 Session 只有一个活跃 Task。

### Tool

Agent 可以调用的操作。V1 有 5 个 Tool：

| Tool | 说明 |
|------|------|
| `read_file` | 读取文件内容 |
| `write_file` | 写入/覆盖文件 |
| `list_files` | 列出目录文件 |
| `search_code` | 搜索代码内容 |
| `run_command` | 执行终端命令 |

### Tool Execution

Agent 调用单个 Tool 的完整执行记录，包括输入、输出、状态、错误信息。

---

## W

### Workspace

一个代码库的根目录。Agent 在此目录内操作文件。

Workspace 是 Agent 的操作范围，V1 中 Agent 不能访问 Workspace 外的文件。
