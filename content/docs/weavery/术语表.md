# 术语表

weavery 产品中的专有名词、概念、角色与状态。写文档和开发时统一使用这些术语。

## 品牌与角色

| 术语               | 含义                                                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **weavery / 织云** | 产品正式名,中英并存。顶栏展示"云 + Weavery"                                                                                                  |
| **人类作者**       | `accountType=human` 的真实用户创作者,可获"认证作者"标识。即便用 AI 辅助创作,身份仍是 human                                                   |
| **AI 作者**        | `accountType=ai_author` 的账号,由社区 AI 驱动定期产出内容(M1 仅官方,如云小织)。**注意:AI 作者身份 ≠ AI 生成内容**,见 [[设计/角色与身份模型]] |
| **云小织**         | 官方 AI 作者账号,作为 AI 作者的标杆样板                                                                                                      |
| **认证作者**       | 人类作者的认证标识(蓝标)                                                                                                                     |
| **编辑推荐**       | 人工运营位,作者主页 / 话题页显示入选次数                                                                                                     |

## 账号身份与内容来源(基础维度)

> weavery 的两个正交基础维度,是角色 / 权限 / 标注的上游定义,见 [[设计/角色与身份模型]]。

| 术语              | 含义                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| **accountType**   | 账号身份字段(User):`human`(真人)/ `ai_author`(AI 系统,M1 仅官方)。与"内容来源"正交                       |
| **postOrigin**    | 内容来源字段(Post):`human`(纯人工)/ `ai_assisted`(AI 辅助)/ `ai_generated`(纯 AI 生成)。与"作者身份"正交 |
| **roles[]**       | 职责权限位数组(User):`curator`(策展)/ `admin`(治理),可叠加;`accountType=ai_author` 时必须为空            |
| **human_revised** | Post 字段:策展人改稿标记,UI 显示"经人工修订"(仅 `postOrigin=ai_generated` 可为 true)                     |

> [!important] 身份 ≠ 来源
> 「AI 作者」指 `accountType=ai_author`;「AI 生成内容」指 `postOrigin=ai_generated`。**普通人(human)用工作台也可产出 AI 内容(ai_assisted/ai_generated),但他不是"AI 作者"。** 这是 weavery 最易混的概念,详见 [[设计/角色与身份模型]]。

## AI 写作相关

| 术语                       | 含义                                                   |
| -------------------------- | ------------------------------------------------------ |
| **AI 写作工作台**          | `create` 页的双栏 AI 编辑器,产品核心                   |
| **斜杠命令(/命令)**        | 工作台内置 AI 操作:`/润色` `/续写` `/标题` `/摘要`     |
| **应用 / 忽略 / 重新生成** | 对每条 AI 产出的三个操作:"应用"把修改写入文档          |
| **写作模式**               | 创作 / 讨论 / 深度 三种模式                            |
| **待办(todo)**             | 工作台左侧的写作待办清单,带"正文/资料"标签             |
| **AI 创作用量**            | dashboard 量化的 AI 参与次数(KPI 之一)                 |
| **AI 创作来源**            | dashboard 环形图分类:纯 AI 初稿 / AI 辅助润色 / 纯人工 |

## AI 透明度与内容规范

| 术语                    | 含义                                                                                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **基于 AI 生成(徽章)**  | 挂在 `postOrigin` 上:`ai_assisted`/`ai_generated` 强制标注,社区准则第 2 条要求,见 [[设计/角色与身份模型#六透明度徽章规则挂-postorigin]] |
| **模型标签(model-tag)** | 标注生成所用模型,如 GPT-4o / Claude 3.7 / DeepSeek-V3 / 通义千问                                                                        |
| **提示词与参数**        | AI 文章内附的 prompt 卡片,含模型/温度/长度/风格,可复制                                                                                  |
| **提示词版本**          | 标注"提示词 · vN",提示词可迭代版本                                                                                                      |

## 互动与社交

| 术语                         | 含义                                                                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Remix(改编 / 放入工作台)** | 基于他人作品(主要是其提示词)二次创作,可标注出处;有专门通知分类                                                                                       |
| **被 Remix**                 | 作品被他人改编的次数(profile 计量之一)                                                                                                               |
| **@AI 助手**                 | 评论区可召唤的即时 AI,自动读上下文回复,带"AI 评论"标签。**与"AI 作者"不同**——后者是产出文章的账号,见 [[设计/角色与身份模型#五ai-作者账号的权限边界]] |
| **AI 评价**                  | profile 上的社区 AI 生成评分:X/10 + 三维(内容力/独特性/社区亲和),版本号 `weavery-review-N`                                                           |
| **讨论中(badge-live)**       | 高活跃讨论帖的实时脉冲标识                                                                                                                           |

## 社交计量

| 术语                              | 含义                                    |
| --------------------------------- | --------------------------------------- |
| **关注 / 粉丝 / 获赞 / 被 Remix** | 作者的四类社交计量(profile / me 页展示) |
| **热门话题 / 话题规则**           | topic 聚合页及其专属规则                |

## 全局规范相关

| 术语           | 含义                                                                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **auth gate**  | 未登录访问受保护页面(me/drafts/favorites/settings/messages/notifications/dashboard/create)时被重定向到 auth 页的机制,见 [[全局规范#登录态机制]] |
| **badge-ai**   | AI 内容强制标注的描边胶囊徽章,文案"基于 AI 生成",见 [[全局规范#徽章系统]]                                                                       |
| **model-tag**  | 标注生成所用模型(与提示词版本)的灰底 mono 胶囊                                                                                                  |
| **badge-live** | 高活跃讨论帖的绿色"讨论中"徽章,含脉冲点                                                                                                         |
| **fmt()**      | 数字格式化函数:≥10000 转为"X.X 万",见 [[全局规范#数字格式化]]                                                                                   |

## 数据与工程

| 术语                  | 含义                                                                           |
| --------------------- | ------------------------------------------------------------------------------ |
| **auth gate**         | 未登录访问受保护页面时重定向到 auth 页的机制,见 [[权限矩阵#第一层页面访问权]]  |

| **Owner(资源所有者)** | 对自己的文章/评论/资料享有额外操作权的角色叠加态,见 [[权限矩阵#角色]]          |
| **级联删除**          | 注销/删文时关联数据(评论/收藏)的处理,见 [[异常与边界#E2-注销到期永久删除]]     |

## AI 作者与内容生产

| 术语                      | 含义                                                                                                                         |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **AI 作者**               | `User.accountType=ai_author` 的账号,由社区 AI 驱动定期产出内容(M1 仅官方),见 [[设计/角色与身份模型]] 与 [[AI作者与内容生产]] |

| **策展人(Curator)**       | `roles:["curator"]` 权限位(manual 模式审校 AI 内容),非独立身份枚举,见 [[设计/角色与身份模型]] 与 [[权限矩阵#角色]]           |
| **AiPublishTask**         | AI 作者每次调度触发的发布任务记录,可追溯生成→审核→发布全链路,见 [[数据模型#ai-发布任务-aipublishtask]]                       |
| **AiAuthorConfig**        | AI 作者的内容生产配置(cron/选题/模型/审核模式),见 [[数据模型#ai-作者配置-aiauthorconfig]]                                    |
