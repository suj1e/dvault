# 功能模块

weavery 的 16 个原型页面归为 **6 大功能区**。本文是清单式概览,每个模块的详细规格后续单独成文。

> [!tip] 阅读建议
> 先通读本页建立全局认知,再按需深入。功能间的关联见 [[信息架构]] 和 [[用户流程]]。

## 一、创作枢纽

### AI 写作工作台 `create`

> weavery 的核心。双栏布局:**左侧 AI 对话 + 右侧文档**,AI 把修改直接写入文档。

| 要素 | 说明 |
|------|------|
| 斜杠命令 | `/润色` `/续写` `/标题` `/摘要` 四种内置 AI 操作,也支持自然语言自由指令 |
| 模型切换 | GPT-4o / Claude 4 / DeepSeek-V3 / 通义千问 |
| 写作模式 | 创作 / 讨论 / 深度 三种 |
| AI 操作 | 每条 AI 产出提供 **忽略 / 重新生成 / 应用** 三个操作,"应用"写入文档 |
| 文档区 | 标题 + 正文,Markdown 工具栏,⌘B 快捷键,实时字数与阅读时长 |
| 待办清单 | 左侧可折叠的本次写作待办(带"正文/资料"标签,可勾选) |
| 自动保存 | 边写边存为草稿(localStorage,"正在保存…/已保存 HH:MM") |
| 发布 | 底部"发布"按钮,点击变绿"已发布" |
| 编辑模式 | `?edit=1` 进入,保存后覆盖原稿 |
| 适配 | 桌面可拖拽 splitter 调左右栏宽;移动端切"对话/文档" Tab |

### 草稿箱 `drafts`

集中管理未发布草稿。每条显示标题、状态、更新时间、字数,以及 **AI 参与标记**(如"AI 起稿"、"AI 续写")。支持继续编辑(跳工作台)、删除(二次确认)。

## 二、内容消费

### 首页信息流 `feed`

内容发现入口,双栏(信息流 + 侧栏)。

- **三个 Tab**:AI 推荐 / AI 发布(仅 AI 生成)/ 关注
- **多种卡片**:大图封面卡、纯文卡、缩略图文卡
- **AI 标识**:带"基于 AI 生成"徽章 + 模型标签(如 GPT-4o)
- **讨论状态**:高活跃帖带脉冲点"讨论中"实时徽章
- **互动**:点赞(数字实时增减)、整卡可点进详情
- **侧栏**:热门话题榜、推荐作者(一键关注)、"让 AI 帮你开始写作"引导

### 帖子详情 `post`

单篇长文阅读 + 完整互动。

- **文章结构**:标题、副标题、作者署名(含角色徽章)、封面、正文、相关作品
- **AI 透明度卡片**:顶部"基于 AI 生成"徽章 + 模型标签 + "提示词 · vN" 版本
- **提示词折叠块**:展开看完整 prompt 与参数(模型/温度/长度/风格),可"复制"或"放入工作台"
- **互动条**:点赞 / 收藏 / 评论数
- **作者专属**:`?owner=1` 显示"编辑 / 删除"(删除二次确认)
- **Remix**:多处"放入工作台 / 开始改编",把作品提示词带入工作台
- **评论区**:支持 `@提及`;**@AI 助手** 触发 AI 读上下文自动回复(带"AI 评论"标签 + 免责说明)

### 作者主页 `profile`

展示作者资料、作品与社区数据。

- **资料头**:头像、昵称、认证徽章(认证作者 / AI 作者)、简介、地区、加入时长
- **数据条**:作品 / 关注 / 粉丝 / 获赞
- **AI 评价**(特色):社区 AI 生成的 X/10 评分 + 三维评分(内容力 / 独特性 / 社区亲和)+ 打字机评语,可"重新生成",附免责声明
- **内容 Tab**:作品列表、简介(关于作者长文 + 常写话题)

## 三、发现

### 搜索 `search`

全局搜索 + 探索发现页。

- **探索态**(无关键词):大搜索框 + 热门搜索 chips + 热门话题卡片 + 推荐作者
- **结果态**:按 全部 / 文章 / 作者 / 话题 分类
- 支持 `?q=` 直接进入结果态

### 话题 `topic`

按主题聚合内容的专题页(类似社区版块)。

- **话题头**:`#话题名`、描述、讨论数 / 关注人数 / 编辑推荐次数
- **关注话题** + **发帖**(跳工作台)
- **排序**:最新 / 热门 / 讨论最多
- **话题规则**:每个话题有专属规则(如"AI 辅助产出请标注")
- 内置约 17 个话题:AI 编程、独立开发者、设计系统、开源商业化、数字游民、提示词、模型对比、梗图、工作流、AI 写作、配色、渐变、效率工具、大模型、职业成长、生活、翻译等

## 四、社交

### 通知中心 `notifications`

聚合社区互动通知。

- **五类筛选**:全部 / 赞与收藏 / 评论 / 关注 / **Remix**
- 按时间分组(今天 / 昨天 / 更早)
- AI 助手的评论通知带"AI 评论"标签
- 支持全部标已读、单条点击已读、回关
- **全局铃铛浮窗**:各页通用,展开最近 3 条 + "查看全部"

### 私信 `messages`

一对一私信(IM 风格)。

- 左侧会话列表(可搜索)+ 右侧聊天线程
- 支持发送当前文章、对方"正在输入"动画
- 会话可含 AI 作者(云小织),其回复可"放进你的 AI 写作工作台"
- 隐私设置可限制"仅关注的人可发"

### 关注 / 收藏

- **关注**:作者、话题;`me` 页管理关注列表
- **收藏夹 `favorites`**:聚合 文章 / 话题 / 作者,各带计数与筛选

## 五、创作者中心

### 我的 `me`

当前用户的个人中心,聚合自己的内容。

- 资料头 + 数据条(已发布文章 / 关注 / 粉丝 / 获赞)
- **四个内容 Tab**:文章 / 草稿 / 收藏 / 关注
- "编辑资料"、"设置"入口

### 创作者数据 `dashboard`

给创作者的周度数据看板。

- **时间范围**:近 7 / 30 / 90 天
- **四项 KPI**:总阅读、互动、**AI 创作用量**、净增关注(带环比)
- **阅读趋势柱状图**(按天/周/月)
- **AI 创作来源环形图**:纯 AI 初稿 / AI 辅助润色 / 纯人工,量化 AI 参与度
- **作品表现排行表**

## 六、账户与治理

### 登录注册 `auth`

- 三态 Tab:登录 / 注册 / 忘记密码
- 注册需同意《社区准则》
- 品牌区呈现口号与三条卖点

### 设置 `settings`

左侧分栏,含:

- **账号**:公开资料、登录与绑定
- **隐私**:私信开关、被关注通知、隐藏关注列表、**允许用我的公开内容训练 AI**、导出数据
- **通知偏好**:各类型通知开关、触达方式(邮件、汇总频率)
- **个性化**:信息流是否展示 AI 内容、默认排序、**AI 写作助手**(默认模型、自动保存、语言偏好)
- **危险区**:注销账号(30 天冷静期)

### 社区准则 `guidelines`

8 条明文规则,既是治理依据也是调性宣示。重点:AI 生成内容必须标注并附模型、分享提示词应附完整输入输出与参数、事实类需人工核实。版本 v1.0。

### 帮助中心 `help`

辅助页面,提供使用指引(原型中为占位)。
