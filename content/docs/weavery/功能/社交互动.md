# 社交互动

weavery 的社交体系:**通知中心**、**私信**、**关注 / 收藏**。

## 通知中心 `notifications`

> 聚合社区互动通知。

### 五类通知 + 筛选

顶部 Tab 按通知类型筛选:

| Tab | 包含 |
|-----|------|
| 全部 | 所有通知 |
| 赞与收藏 | 别人点赞、收藏你的作品 |
| 评论 | 收到的评论(含 [[功能/帖子详情与Remix#@AI-助手|@AI 助手]] 的评论,带"AI 评论"标签) |
| 关注 | 新粉丝 |
| **Remix** | 你的作品被 [[功能/帖子详情与Remix#Remix改编-再创作|Remix 改编]] |

### 时间分组

通知按时间分组展示:
- 今天 / 昨天 / 更早

### 通知项元素

| 元素 | 说明 |
|------|------|
| 头像 | 触发者 |
| 行为描述 | "XX 赞了你的《...》" |
| 时间 | 相对时间 |
| 未读标记 | 小红点 |
| 操作按钮 | "查看" / "回关" |

AI 助手的评论通知带"AI 评论"标签以示区分。

### 操作

| 操作 | 行为 |
|------|------|
| 全部标为已读 | 顶部按钮 |
| 单条点击已读 | 点击通知即标记已读 |
| 回关 | 关注通知可直接"回关"或显示"已互关" |

### 全局铃铛浮窗

**全站通用**(各页顶栏),提供通知速览:

- 点击顶栏铃铛展开
- 显示最近 3 条通知摘要
- "全部已读"按钮
- "查看全部通知 →"链接跳通知中心

## 私信 `messages`

> 一对一私信,IM 风格。

### 布局

| 区块 | 内容 |
|------|------|
| 左侧 | 会话列表(可搜索) |
| 右侧 | 聊天线程 |

移动端:左右切换显示。

### 消息特性

| 特性 | 说明 |
|------|------|
| 消息气泡 | 我 / 对方区分 |
| 按天分隔 | 日期分隔线 |
| 正在输入 | 对方"正在输入"三点动画 |

### 输入区

| 功能 | 说明 |
|------|------|
| 插图 | 发送图片 |
| 发送当前文章 | 把正在看的文章发过去 |
| Enter | 发送 |
| Shift + Enter | 换行 |

### AI 作者会话

会话可包含 AI 作者(云小织):
- 带 AI 标签
- 其回复可"放进你的 AI 写作工作台"

### 隐私控制

- 从作者主页"私信"按钮发起
- 隐私设置可限制"仅关注的人可发"(见 [[功能/账户与治理#设置|设置 → 隐私]])

## 关注

| 对象 | 行为 |
|------|------|
| 作者 | 关注后其作品进 [[功能/信息流|信息流]] 的"关注" Tab |
| 话题 | 关注后其更新进通知 |

### 管理入口

[[功能/创作者中心#我的|我的 → 关注 Tab]] 管理关注列表,可直接取关。

## 我的收藏 `favorites`

> 收藏夹,聚合文章 / 话题 / 作者。

### 筛选 Tab

| Tab | 内容 |
|-----|------|
| 全部 | 所有收藏 |
| 文章 | 收藏的文章 |
| 话题 | 订阅的话题(显示"订阅于…") |
| 作者 | 关注的作者(显示代表作) |

各 Tab 带计数。

### 列表项

| 收藏类型 | 显示 |
|----------|------|
| 文章 | 来源作者、收藏时间、阅读数 |
| 话题 | 订阅时间 |
| 作者 | 代表作 |

### 操作

| 操作 | 适用 |
|------|------|
| 取消收藏 | 文章 |
| 取消订阅 | 话题 |
| 取消关注 | 作者 |

## 业务规则

1. **通知按类型筛选**:五类 Tab 互斥
2. **AI 通知带标签**:AI 助手的评论通知显示"AI 评论"标签
3. **私信可限权**:隐私设置控制谁能发私信
4. **收藏分类管理**:文章/话题/作者分开,操作语义不同(取消收藏/订阅/关注)
