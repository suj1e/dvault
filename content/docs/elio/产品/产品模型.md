# 产品模型

## 实体关系总览

```text
User
  ├── Languages（学习的语言）
  │     ├── Skills（技能：词汇、阅读、听力、写作、口语）
  │     │     └── Exercises（练习记录）
  │     └── Content（学习内容）
  │           ├── Articles（文章）
  │           ├── Videos（视频）
  │           └── Vocabulary（词汇）
  └── Progress（学习进度）
        ├── Streak（连续学习天数）
        ├── Mastery（掌握度）
        └── Errors（错误记录）
```

---

## 实体定义

### Language

**定义**：用户正在学习的语言。

**属性**：
- `id`：语言唯一标识
- `code`：语言代码（如 en、ja、fr）
- `name`：语言名称
- `level`：当前水平（CEFR 参考）
- `goal`：学习目标
- `startedAt`：开始学习时间
- `createdAt`：创建时间

**生命周期**：
- 用户添加新语言时创建
- 用户可以暂停 / 恢复语言学习
- 不删除（历史记录保留）

**用户操作**：
- 添加语言
- 设置学习目标
- 暂停 / 恢复

---

### Skill

**定义**：语言学习的技能维度。

**V1 技能**：
- 词汇（Vocabulary）
- 阅读（Reading）
- 听力（Listening）
- 写作（Writing）
- 口语（Speaking）—— V1 记录，V2 练习

**属性**：
- `id`：技能唯一标识
- `languageId`：所属语言
- `type`：技能类型
- `level`：当前水平
- `mastery`：掌握度（0-100%）
- `exerciseCount`：练习次数
- `correctRate`：正确率

**生命周期**：
- 用户开始学习某语言时自动创建
- 随练习数据更新

---

### Exercise

**定义**：一次具体的练习记录。

**类型**：
- 词汇复习（SRS）
- 阅读理解
- 听力理解
- 写作练习
- 表达练习

**属性**：
- `id`：练习唯一标识
- `languageId`：所属语言
- `skillId`：所属技能
- `type`：练习类型
- `content`：练习内容
- `userAnswer`：用户答案
- `correctAnswer`：正确答案
- `isCorrect`：是否正确
- `duration`：用时（秒）
- `createdAt`：练习时间

**生命周期**：
- 练习完成后创建
- 永久保留，用于错误分析和进度统计

---

### Content

**定义**：学习内容。

**类型**：
- Article：文章（内置或用户上传）
- Video：视频（带字幕）
- Vocabulary：词汇（用户收集或系统推荐）

**属性**：
- `id`：内容唯一标识
- `languageId`：所属语言
- `type`：内容类型
- `title`：标题
- `source`：来源（内置 / 用户上传 / URL）
- `difficulty`：难度等级
- `tags`：标签
- `createdAt`：创建时间

---

### Vocabulary

**定义**：词汇条目。

**属性**：
- `id`：词汇唯一标识
- `languageId`：所属语言
- `word`：单词
- `definition`：释义
- `pronunciation`：发音（音标 / 音频）
- `example`：例句
- `level`：词汇等级
- `nextReviewAt`：下次复习时间（SRS）
- `reviewCount`：复习次数
- `mastery`：掌握度
- `createdAt`：创建时间

**生命周期**：
- 用户查词或系统推荐时创建
- 随 SRS 复习更新

---

### Progress

**定义**：学习进度汇总。

**属性**：
- `id`：进度唯一标识
- `languageId`：所属语言
- `streak`：连续学习天数
- `totalStudyTime`：总学习时间
- `totalExercises`：总练习数
- `averageAccuracy`：平均正确率
- `masteryMap`：各技能掌握度
- `weakPoints`：薄弱点列表
- `updatedAt`：更新时间

**生命周期**：
- 每次练习后更新

---

### Error

**定义**：用户犯过的错误。

**属性**：
- `id`：错误唯一标识
- `languageId`：所属语言
- `skillId`：所属技能
- `type`：错误类型（拼写、语法、发音、理解）
- `content`：错误内容
- `correctContent`：正确内容
- `context`：上下文
- `occurrences`：出现次数
- `lastOccurredAt`：最后一次出现时间
- `createdAt`：创建时间

**生命周期**：
- 用户犯错时创建或更新
- 用于针对性练习推荐

---

## 实体关系

| 关系 | 说明 |
|------|------|
| User 1:N Language | 一个用户可学习多门语言 |
| Language 1:N Skill | 一门语言有多个技能维度 |
| Language 1:N Content | 一门语言有多个学习内容 |
| Language 1:N Vocabulary | 一门语言有多个词汇 |
| Language 1:N Exercise | 一门语言有多次练习 |
| Language 1:1 Progress | 一门语言对应一个进度汇总 |
| Exercise 0:N Error | 一次练习可能产生多个错误 |

## V1 推迟的实体

| 实体 | 原因 |
|------|------|
| Community | V1 是个人学习工具 |
| Social | V1 不涉及社交 |
| Achievement | V1 不做游戏化 |
| Gamification | V1 保持学习严肃性 |
| AI Tutor | V1 不提供实时对话 |
| Speaking Practice | V1 只记录，不练习 |
| Writing Correction | V1 基础反馈，不深度批改 |
| Subscription | V1 不考虑 |
