# V1 范围

## V1 完整闭环

```text
User
  ↓
Input（阅读 / 听力 / 查词）
  ↓
Practice（词汇 / 阅读 / 写作）
  ↓
Feedback（即时反馈 + 错误记录）
  ↓
Progress（进度可视化 + 掌握度）
  ↓
Review（SRS 复习）
  ↓
Loop（回到 Input）
```

V1 的目标是**形成完整的学习闭环**，而不是堆功能。

## V1 模型决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 核心闭环 | 理解 → 练习 → 应用 → 反馈 | 符合语言学习科学 |
| 技能维度 | 词汇、阅读、听力、写作、口语 | 覆盖主要语言能力 |
| 口语练习 | V1 只记录，不练习 | 口语需要复杂 ASR/TTS，V2 考虑 |
| 内容来源 | 内置 + 用户导入 | 保持内容质量，同时给予自由度 |
| 反馈方式 | 基础判分 + 错误记录 | 简单可靠，不追求 AI 深度批改 |
| 进度可视化 | 掌握度 + 趋势图 | 直观展示进步 |

---

## V1 不做什么的底线

> **V1 必须形成完整的学习闭环，而不是堆功能。**

判断标准：
1. 这个功能是否直接服务于"语言学习"？
2. 没有这个功能，用户能否完成一次完整的学习循环？
3. 这个功能是否可以在 V1 之后通过更新添加？

如果三个答案都是"否 → 是 → 是"，那么它属于 V1。否则推迟。
