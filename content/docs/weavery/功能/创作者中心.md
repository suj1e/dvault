# 创作者中心

创作者相关功能:**数据看板**、**我的**、**草稿箱**。

## 创作者数据 `dashboard`

> 给创作者的周度数据看板,量化创作表现与 AI 参与度。

### 时间范围

顶部切换:近 **7 / 30 / 90** 天。

### 四项 KPI

| 指标 | 说明 |
|------|------|
| 总阅读 | 累计阅读量(带环比涨跌) |
| 互动 | 点赞 + 评论 + 收藏(带环比) |
| **AI 创作用量** | 使用 AI 创作的次数(带环比) |
| 净增关注 | 新增粉丝 - 取关(带环比) |

### 阅读趋势

- **柱状图**,按天 / 周 / 月 聚合

### AI 创作来源(特色)

环形图量化 AI 参与度,把创作拆成三类:

| 来源 | 说明 |
|------|------|
| 纯 AI 初稿 | AI 起稿为主 |
| AI 辅助润色 | 人工起稿 + AI 润色 |
| 纯人工 | 无 AI 参与 |

中心标注整体 AI 参与率(如"68% AI 参与")。

> [!important] AI 参与度可视化
> 这是 weavery 的特色——**量化并展示 AI 在创作中的参与度**,呼应"AI 透明"文化。

### 作品表现排行

表格列出 Top 作品:
- 标题、专栏、阅读数、互动数、占比条

## 我的 `me`

> 当前用户的个人中心,聚合自己的内容。

### 结构

```
┌─────────────────────────────────────┐
│  资料头 + 数据条                     │
│  头像 昵称                           │
│  已发布 N │ 关注 N │ 粉丝 N │ 获赞 N│
│  [编辑资料] [设置]                   │
├─────────────────────────────────────┤
│  [文章] [草稿] [收藏] [关注]         │
│  对应内容列表                        │
└─────────────────────────────────────┘
```

### 四个内容 Tab

| Tab | 内容 |
|------|------|
| 文章 | 已发布作品(带"已发布"状态标) |
| 草稿 | 内嵌草稿管理(继续编辑 / 删除) |
| 收藏 | 跳 [[功能/社交互动#我的收藏|收藏夹]] |
| 关注 | 关注列表(可直接取关) |

### 入口按钮

| 按钮 | 跳转 |
|------|------|
| 编辑资料 | [[功能/账户与治理#设置|设置 → 账号]] |
| 设置 | [[功能/账户与治理#设置|设置]] |

## 草稿箱 `drafts`

> 集中管理未发布的草稿。

### 概览统计

| 指标 | 说明 |
|------|------|
| 全部草稿数 | |
| **AI 辅助创作**篇数 | 标记使用了 AI 的草稿 |
| 累计字数 | |

### 草稿列表项

| 字段 | 说明 |
|------|------|
| 标题 | 或"无标题 · ..." |
| 状态 | |
| 更新时间 | |
| 字数 | |
| **AI 参与标记** | chip 标注(如"AI 起稿"、"AI 续写") |

### 操作

| 操作 | 行为 |
|------|------|
| 继续编辑 | 跳 [[功能/AI写作工作台|工作台]] `?draft=` 载入 |
| 删除 | **二次确认** |
| 新建写作 | 跳工作台新建 |

### 空状态

无草稿时显示空状态引导。

## 业务规则

1. **AI 参与全程可追溯**:草稿、看板都量化/标注 AI 参与度
2. **看板带环比**:KPI 显示同比涨跌
3. **删除二次确认**:草稿删除需确认
4. **me 页内嵌轻量管理**:me 的草稿/收藏/关注 Tab 对应独立完整页(drafts / favorites)
