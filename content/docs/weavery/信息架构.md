# 信息架构

weavery 采用 **顶部全局顶栏 + 页脚导航** 的组合,无左侧主导航条。

## 全局顶栏(全站通用)

```
顶栏
├── 品牌 logo「织云 Weavery」        → feed
├── 全局搜索框(⌘K)                 → search
├── [按钮] AI 写作(全站 CTA)        → create
├── 铃铛通知浮窗                     → notifications
├── [按钮] 登录                      → auth
└── 头像「我」                       → me
```

## 页面层级

```
内容消费层
├── feed 首页信息流
│   └── 侧栏:热门话题 → topic;推荐作者 → profile;AI 写作引导 → create
├── post 帖子详情
│   ├── → create(编辑 / Remix)
│   ├── → profile(作者)
│   └── #comments(评论,@AI 助手)
├── topic 话题页(→ create 发帖)
├── search 搜索(→ post / profile / topic)
└── profile 作者主页(→ messages 私信)

创作与管理层(需登录)
├── create AI 写作工作台(枢纽)
│   ├── ← drafts(载入草稿)
│   └── ← post(编辑 / Remix)
├── drafts 草稿箱(→ create)
├── dashboard 创作者数据
├── me 我的(内嵌 文章/草稿/收藏/关注 四 Tab)
├── favorites 我的收藏
├── messages 私信
├── notifications 通知中心
└── settings 设置

账户与治理
├── auth 登录/注册/找回
├── guidelines 社区准则
└── help 帮助中心
```

## 枢纽节点说明

两个页面是高频枢纽:

| 枢纽 | 被谁指向 | 作用 |
|------|------|------|
| **`create` 工作台** | 首页侧栏、话题页"发帖"、帖子页"编辑/放入工作台/Remix"、草稿箱、me 页 | 创作的总入口,被 5+ 处指向 |
| **`me` 我的** | 顶栏头像 | 登录后的个人中心,内嵌轻量管理 |

`me` 页内嵌了草稿/收藏/关注的轻量管理,同时也有对应的独立完整页(`drafts` / `favorites`)。

## 页脚(全站通用)

```
搜索 · 通知 · 社区准则 · 帮助中心
```
